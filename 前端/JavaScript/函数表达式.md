	<div><p>##函数表达式<br />
定义函数表达式的方式：</p>
<ol>
<li>函数声明</li>
</ol>
<div><pre><code><span>    function functionName(arg0, arg1, arg2) {</span>
<span>      // body...</span>
<span>    }</span>
</code></pre></div>
<ol start="2">
<li>函数表达式</li>
</ol>
<div><pre><code><span>    var functionName = function(arg0, arg1, arg2) {</span>
<span>      // body...</span>
<span>    }</span>
</code></pre></div>
<blockquote>
<p>区别：{函数提升}，使用函数声明定义函数在执行代码之前会先读取函数声明，这就意味着可以把函数声明放在调用它的语句后面。函数表达式没有此特点。</p>
</blockquote>
</div>
