### CSS初探
> CSS(层叠样式表) 用来规定HTML文档的呈现形式

### 1. 样式定义

1. 元素内嵌样式
2. 文档内嵌样式
3. 外部样式表

```
<link rel="stylesheet" type="text/css" href="-------.css"/>
```

在样式表中引用其他样式表
```
@(Html5)import "styles.css"
```

声明样式表的字符编码

```
@charset "UTF-8"
```

### 2. 样式层叠和继承

1. 样式层叠
	1. 浏览器显示元素时求索一个CSS属性值得次序
		- 元素内嵌样式 (用元素的全局属性 style 定义的样式)
		- 文档内嵌样式 (定义在 style 元素中的样式)
		- 外部样式 (使用 link 元素导入的样式)
		- 用户样式 (用户定义的样式)
		- 浏览器样式 (浏览器应用的默认样式)
	2. 用重要样式调整层叠次序
		在样式声明后附上`!important`即可将对应属性值标记为重要, 浏览器会优先考虑.

2. 样式继承
父元素的属性可被子元素继承, 但并非所有的CSS属性均可继承; 与元素外观(文字, 颜色, 字体等)相关的样式会被继承, 与元素在页面上的布局相关的样式不会被继承. 在样式中使用`inherit` 这个特别设立的值可以强行实施继承. 

### 3. CSS中的颜色
> CSS扩展颜色名表: [CSS颜色](www.w3.org/TR/css3-color)

- 使用规定的颜色名称
- 设置红, 绿, 蓝三种颜色成分的值, 使用十进制时用逗号分隔, 十六进制前加#;

#### 4. CSS中的长度
> 设置长度时数字和标识符需连在一起

1. 绝对长度

| 单位标识符|     说明 |
| :-------- | :--------|
| in    |     英寸 |
| cn    |     厘米 |
| mm    |     毫米 |
| pt    |   磅(1磅 = 1/72英寸) |
| pc    |   pica(1pica = 1/6英寸) |

2. 相对长度

| 单位标识符|     说明 |
| :-------- | :--------|
| em    |   与元素字号挂钩 |
| ex    |   与元素字体的"x高度"挂钩 |
| rem   |   与根元素的字号挂钩 |
| px    |   CSS像素(假定显示设备的分辨率为96dpi) |
| %     |   另一属性的值得百分比 |

3. CSS角度

| 单位标识符|     说明 |
| :-------- | :--------|
| deg     |   度(0deg ~ 360deg) |
| grad    |   百分度(0grad ~ 400grad) |
| rad     |   弧度(0rad ~ 6.28rad) |
| turn    |   圆周(1trun = 360deg) |

4. 时间

| 单位标识符|     说明 |
| :-------- | :--------|
| s     |   秒   |
| ms    |   毫秒 |
