## Collection

### List 
#### ArrayList
本质：数组；
优点：动态扩容；支持下标随机访问读取速度快`O(1)`；
缺点：写入速度慢（数据移动）；内存利用率低(连续内存空间)；
线程：不安全；
使用场景：多读取少写入的场景。

#### LinkedList
本质：链表
优点：写入速度快，首尾两端写入速度更快`O(1)`，平均写入速度`O(n)`；
缺点：访问速度慢(每次查找都需要从头遍历)；内存利用率高；
线程：不安全；
使用场景：多写入少读取的场景，尤其是需要栈的场景。

#### Vector
本质：数组 + synchronized；
优点：同 ArrayList；
缺点：同 ArrayList；
线程：安全；
使用场景：高并发前提下，读操作`不远多于`写操作且不需要频繁写入的场景可以`考虑`使用；

##### Stack
本质：Vector
优点：同 ArrayList；
缺点：同 ArrayList；
线程：安全；
使用场景：推荐使用 `Deque` 子类替代。

#### CopyOnWriteArrayList
本质：数组 + synchronized + 数据拷贝
优点：同 ArrayList；
缺点：同 ArrayList；
线程：安全；
使用场景：高并发前提下，读操作`远多于`写操作的场景可以`考虑`使用；

## 遍历
### 遍历方式
```java

numbers.add(12);
numbers.add(8);
numbers.add(2);
numbers.add(23);
```


#### 迭代器循环遍历
遍历过程中移除元素：
```java
ArrayList<Integer> numbers = new ArrayList<Integer>();
numbers.add(12);
numbers.add(8);
numbers.add(2);
numbers.add(23);
Iterator<Integer> it = numbers.iterator();
while(it.hasNext()) {
    Integer i = it.next();
    if(i < 10) {  
        it.remove();  // 删除小于 10 的元素
    }
}
```
> 注意：这种遍历方式可以防止 `fail-fast`

#### foreach 循环遍历
`foreach 循环` 实际上是一种语法糖，编译器在编译时会将其转换为相应的 `for 循环` 或 `迭代器循环`。使用 `foreach 循环` 可以简化代码编写，使代码更加易读和简洁。

### 防止 `ConcurrentModificationException`
循环遍历集合数据时，如果在遍历过程中修改了集合的结构（例如添加、删除元素），就有可能抛出 `ConcurrentModificationException` 异常。
防止 `ConcurrentModificationException` 异常可采用如下方式：

* 并发场景下使用并发集合类：如 `ConcurrentHashMap` 或 `CopyOnWriteArrayList`。
* 单线程场景下使用迭代器遍历：如果需要在遍历过程中对集合进行修改操作，可以使用迭代器的方式进行遍历，并使用迭代器的 `remove` 方法来删除元素（上面的示例）。
* 使用同步机制：使用同步机制来保护对集合的修改操作和遍历操作的原子性。确保同一时间只有一个线程能够修改集合。
* 使用数据副本：可以先创建一个集合的备份（副本），然后在备份集合上进行遍历操作。注意，备份集合可能会占用额外的内存空间。

## 同步容器和并发容器
**`同步容器`**：指在容器内部实现了对共享数据的同步保护，以防止多个线程同时访问和修改数据而导致的数据竞争和不一致性。
**`并发容器`**：指在容器内部使用了特定的数据结构和算法，以支持并发访问和修改数据，从而提高并发性能。
