### 简介
`RandomAccessFile` 是 `Java` 提供用于处理文件类，它允许从任何位置访问文件。`RandomAccessFile` 的文件访问行为类似于访问文件系统中一个大的字节数组。它提供一个文件指针，可以想象成指向数组的索引，可以从指针开始的地方对文件进行读写。当执行读写操作后，文件指针也将移动到读写之后的位置。

### 方法说明
**`构造函数：`**

`r`：以只读方式打开指定文件。如果试图对该 `RandomAccessFile` 指定的文件执行写入方法则会抛出IOException;
`rw`：以读取、写入方式打开指定文件。如果该文件不存在，则尝试创建文件
`rws`：以读取、写入方式打开指定文件。相对于 `rw` 模式，还要求对文件的内容或元数据的每个更新都同步写入到底层存储设备，默认情形下(`rw` 模式下)，是使用 `buffer` 的，只有 `cache` 满的或者使用 `RandomAccessFile.close()` 关闭流的时候儿才真正的写到文件
`rwd`：与 `rws` 类似，只是仅对文件的内容同步更新到磁盘，而不修改文件的元数据

**`文件指针操作：`**

| 方法 | 说明 |
| --- | --- |
| skipBytes(int): int | 跳过输入的字节数。输入参数大于0才有效，返回值为实际跳过的字节数，返回值小于输入字节数或为0则表示文件指针已经到达文件末尾。 |
| getFilePointer(): long | 获取当前文件指针的位置 |
| seek(long): void | 移动文件指针到目标位置，范围：[0,length()-1) |
| length(): long | 文件长度 |
| setLength(long): void | 设置文件长度，若参数值小于当前文件长度则截取文件，若参数值大于当前文件长度则扩展文件 |

**`读：`**

| 方法 | 说明 |
| --- | --- |
| readInt()... | 支持从当前文件指针位置读取一个int值 |
| ... | 支持读取所有基本数据类型，readLong()等 |
| readUTF() | 读取一个字符串 |
| readLine() | 读取一行，一行数据以回车换行符为止`\r\n` |
| read(): int | 读取一个字节，内部由 readByte() 实现 |
| read(byte[], int, int): int | 目标范围字节，返回值为实际读取的字节数 |
| readFull(byte[], int, int): int | 目标范围字节，返回值为实际读取的字节数 |

> 注意：读取方法都是阻塞方法。

`read` 和 `readFull` 的区别在于，`readFully` 在读取数据的时候，会一直把缓冲区读满，否则一直处于阻塞状态。 而 `read` 方法只是将字节流中的数据读完。

**`写：`**
写方法和读方法对应。

### 优缺点

优点：

* 随机访问：支持文件随机访问；
* 大文件处理：随机访问的能力提供了它仅需要在内存中保留必要部分数据的能力，减少了内存的使用。

缺点：

* 线程不安全：需要开发者使用锁或其他同步方式保证数据安全；
* 错误处理：`RandomAccessFile` 读写过程中发生错误有时不会抛出异常，而是返回 0 或 -1；
* 只支持文件：不支持数据流。
