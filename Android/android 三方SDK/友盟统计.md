## 友盟统计

### 1. 检查版本更新
示例:

```
				//仅在wifi环境下更新
				UmengUpdateAgent.setUpdateOnlyWifi(true);
                UmengUpdateAgent.setUpdateAutoPopup(false);
                UmengUpdateAgent.setUpdateListener(new UmengUpdateListener() {

                    @Override
                    public void onUpdateReturned(int updateStatus,
                                                 UpdateResponse updateInfo) {
                        switch (updateStatus) {
                            case 0://有更新
                                //友盟自动检测更新
                                UmengUpdateAgent.update(SecurityCenterActivity.this);
                                break;
                            case 1://无更新
                                FoToast.toast(SecurityCenterActivity.this, getString(R.string.newest_version_code));
                                break;

                            case 2://非wifi状态
                                FoToast.toast(SecurityCenterActivity.this, getString(R.string.suggest_wifi));
                                break;

                            case 3://请求超时
                                FoToast.toast(SecurityCenterActivity.this, getString(R.string.newest_version_code));
                                break;
                        }
                    }
                });

                UmengUpdateAgent.update(this);
```
