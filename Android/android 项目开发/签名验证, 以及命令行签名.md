### 签名验证, 以及命令行签名

@(android 项目开发)

#### V2签名
> 必须说明的是，v2签名方式时在Android7.0后才推出的，所以只有版本>25的SDK\build-tools\中才能找到apksigner.jar。

打开命令行, 进入到`apksigner.jar`文件所在的目录, 输入一下命令, 回车.

```
java -jar apksigner.jar sign --ks `签名文件地址` --ks-key-alias `别名` --ks-pass pass:`签名文件密码` --key-pass pass:`签名文件密码` --out `签名后文件` `需签名文件`
```

别名:					`wukongtv`
签名文件密码:		`wukongtv888`

例子:

```
java -jar apksigner.jar sign  --ks key.jks  --ks-key-alias releasekey  --ks-pass pass:pp123456  --key-pass pass:pp123456  --out output.apk  input.apk
```

jarsigner -verbose -keystore `keystorepath` -signedjar `signedapkpath` `unsignapkpath` `别名`

#### 查看apk签名
> filepath 为 META_INF/*.RSA

```
keytool -printcert -file `filepath`
```

#### 查看签名文件签名

```
keytool -list -v -keystore `filepath`
```
