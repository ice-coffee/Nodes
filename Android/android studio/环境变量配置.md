`Linux` 环境下：
打开你的 `~/.bashrc` 或 `~/.zshrc` 文件，这取决于你使用的是 Bash 还是 Zsh。

如果你想查看当前使用的是哪个 shell，可以在终端中运行以下命令：
```
echo $SHELL
```
这将输出当前使用的 shell 的路径。通常，Bash 的路径是 /bin/bash，而 Zsh 的路径是 /bin/zsh。

以 `~/.bashrc` 为例。


在文件末尾添加以下行，替换 <Your Android Studio Path> 为你的 Android Studio 安装路径：
export PATH=$PATH:<Your Android Studio Path>/bin

例如：
export PATH=$PATH:/home/your_username/Android/android-studio/bin

保存并关闭文件，然后运行以下命令更新配置：

source ~/.bashrc   # 如果使用的是 Bash
source ~/.zshrc    # 如果使用的是 Zsh

步骤 3：配置 ADB
打开 Android Studio，并打开 SDK Manager（通过 "Configure" -> "SDK Manager"）。

在 SDK Platforms 标签下，确保 "Android SDK Platform" 和 "Google APIs" 已安装。

切换到 SDK Tools 标签，确保 "Android SDK Build-Tools"、"Android Emulator" 和 "Android SDK Platform-Tools" 已安装。
