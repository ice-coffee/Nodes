## ijkplayer

[ijkplayer入门之目录介绍及编译](https://blog.csdn.net/jack123lian/article/details/78974268)

Standard options - 标准的选择
Licensing options - 许可选项
Configuration options - 配置选项
Program options - 程序选项
Documentation options - 文档选项
Component options - 组件的选择
	1. avcodec -- FFmpeg中的编解码库
	2. avdevice -- FFmpeg中和多媒体设备交互的类库
	3. avformat -- FFmpeg中的多媒体容器库
Hardware accelerators - 硬件加速器
Individual component options - 组件的选择
protocols - 协议
decoder - 译码器
parser - 解析器
muxer - 音视频文件封装器
demuxer - 音视频文件解封装器
