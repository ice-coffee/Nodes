#### 常见单位

* `px`：像素单位，代表一个像素点；
* `dpi`：像素密度，指屏幕对角线每英寸的像素点个数；
* `density`：屏幕密度（`density = dpi / 160`）；
* `dp / dip`：`px = dp * (dpi / 160) = dp * density`；
* `sp`：默认情况下，`sp` 单位与 `dp` 大小相同，但它会根据用户的首选文本大小来调整大小。

#### `Android` 密度限定符

* `ldpi`：低密度，`~120dpi`
* `mdpi`：中密度，`~160dpi`
* `hdpi`：高密度，`~240dpi`
* `xhdpi`：加高密度，`~320dpi`
* `xxhdpi`：超超高密度，`~480dpi`
* `xxxhdpi`：超超超高密度，`~640dpi`

如果设配密度所对应的 `hdpi` 没有资源，则会先向上查找，如果找不到则向下查找。

#### `mipmap vs drawable`

某些应用启动器显示的应用图标会比设备的密度级别所要求的大差不多 `25%`。

例如，如果设备的密度存储分区为 `xxhdpi`，而您提供的最大应用图标密度级别为 `drawable-xxhdpi`，则启动器应用会放大此图标，这会导致它看起来不太清晰。因此，您应在 `mipmap-xxxhdpi` 目录中提供一个密度更高的启动器图标，而后启动器便可改用 `xxxhdpi` 资源。

由于应用图标可能会像这样放大，因此您应将所有应用图标都放在 `mipmap` 目录中，而不是放在 `drawable` 目录中。
