### 分辨率
显示分辨率（屏幕分辨率）是屏幕图像的精密度，是指显示器所能显示的像素有多少。显示分辨率一定的情况下，显示屏越小图像越清晰，反之，显示屏大小固定时，显示分辨率越高图像越清晰。

### 码率（比特率）
码率是指每秒传输的数据量，单位为bps（Bit Per Second），传输的数据为数字信号，单位为bit，比特率越高，传送数据越快，音频和视频质量越高。

这也是为什么像素同为1080P的视频，大小却不同的原因。

假设一个视频的大小为1G，时长为100分钟，则计算如下：
- 时长 = 100M=100X60S=6000s
- 大小 = 1GB=1024MB= 1024X1024KB=1024X1024X1024Byte=1024X1024X1024X8bit=8589934592bit
- 码率 = 大小 / 时长 = 8589934592/6000 = 1.4Mbit/s

> 计算机存储信息的最小单位：bit(比特)，存放一位二进制数，即 0 或 1。
> - 1B  = 8bit,
> - 1KB = 1024B,
> - 1MB = 1024KB,
> - 1GB = 1024MB.

### 帧率
每秒显示的帧数。高的帧率可以得到更流畅、更逼真的动画。一般来说30fps就是可以接受的，但是将性能提升至60fps则可以明显提升交互感和逼真感，但是一般来说超过75fps一般就不容易察觉到有明显的流畅度提升了。如果帧率超过屏幕刷新率只会浪费图形处理的能力，因为监视器不能以这么快的速度更新，这样超过刷新率的帧率就浪费掉了。
