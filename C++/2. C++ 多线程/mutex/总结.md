### 互斥锁
`c++` 中提供了四种锁：

* `mutex`：不可重入锁
* `recursive_mutex`：可重入锁
* `timed_mutex`：超时锁
* `recursive_timed_mutex`：超时重入锁

#### mutex / recursive_mutex

* `void lock()`：加锁，阻塞当前线程；
* `bool try_lock()`：尝试加锁并返回加锁结果；
* `void unlock()`：解锁；

#### timed_mutex / recursive_timed_mutex

* `void lock()`：加锁，阻塞当前线程；
* `bool try_lock()`：尝试加锁并返回加锁结果；
* `void unlock()`：解锁；
* `template <class Rep, class Period> bool try_lock_for(const chrono::duration<Rep, Period>& rel_time)`：在指定的 timeout 时间段内尝试获取锁，超时返回 false；
* `template <class Clock, class Duration> bool try_lock_until(const chrono::time_point<Clock, Duration>& abs_time)`：在指定的 time_point 时间点前尝试获取锁，超时返回 false；

**`示例：`**
```c++
#include <iostream>
#include <mutex>
#include <thread>
#include <chrono>

std::timed_mutex tmtx;

void worker(int id) {
    // 尝试在 100ms 内获取锁
    if (tmtx.try_lock_for(std::chrono::milliseconds(100))) {
        std::cout << "Thread " << id << " acquired the lock.\n";
        std::this_thread::sleep_for(std::chrono::milliseconds(200)); // 模拟操作
        tmtx.unlock();
    } else {
        std::cout << "Thread " << id << " failed to acquire the lock.\n";
    }
}

int main() {
    std::thread t1(worker, 1);
    std::thread t2(worker, 2);
    t1.join();
    t2.join();
    return 0;
}
```

### 包装器

| 特性 | std::lock_guard | std::unique_lock |
| --- | --- | --- |
| 自动加锁 | 解锁	构造时立即加锁，析构时自动解锁 | 可延迟加锁（通过参数控制） |
| 手动解锁 | ❌ 不支持 | ✅ 支持 unlock() |
| 所有权转移 | ❌ 不可移动或复制 | ✅ 可移动（通过 std::move） |
| 与条件变量兼容 | ❌ 不兼容（需手动管理锁） | ✅ 兼容（如 std::condition_variable::wait） |
| 性能开销 | 低（无额外状态） | 略高（维护更多状态信息） |

**`示例：`**
```c++
std::mutex mtx;

{
    std::lock_guard<std::mutex> lock(mtx); // 立即加锁
    // 临界区操作...
} // 自动解锁
```

```c++
std::mutex mtx;
std::unique_lock<std::mutex> lock(mtx, std::defer_lock); // 延迟加锁
lock.lock(); // 手动加锁
// 临界区操作...
lock.unlock(); // 手动解锁（可选）
```

### condition_variable

在 `C++` 中，`std::condition_variable` 是线程同步的重要工具，用于在多线程环境中实现 条件等待 和 线程间通信。它通常与 `std::mutex` 结合使用，用来阻塞一个或多个线程，直到某个条件被满足。

**`函数：`**

* `wait()`：阻塞当前线程，直到被唤醒（需搭配 mutex 使用）；
* `wait_for()`：/ wait_until()	带超时的等待（C++11 起支持）；
* `notify_one()`：唤醒 一个 正在等待的线程；
* `notify_all()`：唤醒 所有 正在等待的线程；

**`示例：`**

```c++
#include <condition_variable>
#include <iostream>
#include <mutex>
#include <string>
#include <thread>
 
std::mutex m;
std::condition_variable cv;
std::string data;
bool ready = false;
bool processed = false;
 
void worker_thread()
{
    // 等待直至 main() 发送数据
    std::unique_lock lk(m);
    cv.wait(lk, []{ return ready; });
 
    // 等待后，我们占有锁
    std::cout << "工作线程正在处理数据\n";
    data += "（处理后）";
 
    // 发送数据回 main()
    processed = true;
    std::cout << "工作线程指示数据已经处理完成\n";
 
    // 通知前完成手动解锁，以避免等待线程才被唤醒就阻塞（细节见 notify_one）
    lk.unlock();
    cv.notify_one();
}
 
int main()
{
    std::thread worker(worker_thread);
 
    data = "数据样例";
    // 发送数据到 worker 线程
    {
        std::lock_guard lk(m);
        ready = true;
        std::cout << "main() 指示数据已准备好进行处理\n";
    }
    cv.notify_one();
 
    // 等候 worker
    {
        std::unique_lock lk(m);
        cv.wait(lk, []{ return processed; });
    }
    std::cout << "返回 main()，data = " << data << '\n';
 
    worker.join();
}
```

### 防死锁

* `std::lock`：管理互斥量，防止死锁；
* `std::scoped_lock（c++17）`：更简便；

**`示例：`**
```c++
#include <mutex>

std::mutex mtx1, mtx2;

void safe_operation() {
    // 使用 std::lock 原子化锁定两个互斥量
    std::lock(mtx1, mtx2);

    // 锁定后，通过 RAII 包装类管理锁（自动释放）
    std::lock_guard<std::mutex> lock1(mtx1, std::adopt_lock); // adopt_lock 表示已锁定
    std::lock_guard<std::mutex> lock2(mtx2, std::adopt_lock);

    // 临界区操作...
} // 自动解锁
```
