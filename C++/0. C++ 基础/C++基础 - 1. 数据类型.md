### 数据类型修饰符

* `signed`：修饰的数据类型第一位是符号位，取值范围包含负数；
* `unsigned`：修饰的数据类型没有符号位，取值范围不包含负数；
* `short`：短类型
* `long`：长类型
* `long long`：超长类型（C++11新增）

**`常见类型`**：

| 类型 | 字节数 | 范围 |
| --- | :---: | --- |
| char | 1 | -128 ~ 127 |
| unsigned char | 1 | 0 ~ 255 |
| signed char | 1 | -128 ~ 127 |
| int | 4 | -2147483648 ~ 2147483647 |
| unsigned int | 4 | 0 ~ 4294967295 |
| signed int | 4 | -2147483648 ~ 2147483647 |
| short int | 2 | -32768 ~ 32767 |
| unsigned short int | 2 | 0 ~ 65,535 |
| signed short int | 2 | -32768 ~ 32767 |
| long int | 4 | * |
| signed long int | 4 | * |
| unsigned long int | 4 | * |
| long long int | 8 | * |
| float | 4 | * |
| double | 8 | * |
| long double | 16 | * |
| wchar_t | 2 或 4 | 1 个宽字符 |

注意：

* 默认情况下，`int、short、long`都是带符号的，即 `signed`。
* 修饰符 `signed、unsigned、long` 和 `short` 可应用于整型，`signed` 和 `unsigned` 可应用于字符型，`long` 可应用于双精度型。
* 修饰符 `signed` 和 `unsigned` 也可以作为 `long` 或 `short` 修饰符的前缀。
* `C++` 允许使用速记符号来声明无符号短整数或无符号长整数。您可以不写 `int`，只写单词 `unsigned、short` 或 `long，int` 是隐含的。
* `long int` == `int`。

### 非平台相关的数值类型
对于不同平台来说，数值类型的大小可能并不相同。所以最好使用`int32_t`、`int64_t`等标准整数类型，这些类型在C++标准库中有明确定义的大小，不受编译器和平台的影响。例如：

* `int8_t`：8位的有符号整数。
* `int16_t`：16位的有符号整数。
* `int32_t`：32位的有符号整数。
* `int64_t`：64位的有符号整数。
* `uint8_t`：8位的无符号整数。
* `uint16_t`：16位的无符号整数。
* `uint32_t`：32位的无符号整数。
* `uint64_t`：64位的无符号整数。

### 类型判断
[C++ typeid关键字详解](https://blog.csdn.net/gatieme/article/details/50947821)

通过 `typeid(xxx).name()` 可以在运行时获取变量类型。

**`非多态：`**
```c++
#include <iostream>
using namespace std;

class base
{
public :
    void m(){cout<<"base;"<<endl;}
};
class derived : public base
{
public:
    void m(){cout<<"derived;"<<endl;}
};

int main(int argc, char const *argv[])
{
    base * p = new derived;
    p->m();
    cout<<"typeid(p) == typeid(base*) -> "<<(typeid(p) == typeid(base*))<<endl;
    cout<<"typeid(p) == typeid(derived*) -> "<<(typeid(p) == typeid(derived*))<<endl;
    cout<<"typeid(*p) == typeid(base) -> "<<(typeid(*p) == typeid(base))<<endl;
    cout<<"typeid(*p) == typeid(derived) -> "<<(typeid(*p) == typeid(derived))<<endl;
    return 0;
}

输出：----------------->>
base;
typeid(p) == typeid(base*) -> 1
typeid(p) == typeid(derived*) -> 0
typeid(*p) == typeid(base) -> 0
typeid(*p) == typeid(derived) -> 1
```

**`多态：`**
```c++
......
virtual void m(){cout<<"base;"<<endl;}
......
```
输出：
```c++
derived;
typeid(p) == typeid(base*) -> 1
typeid(p) == typeid(derived*) -> 0
typeid(*p) == typeid(base) -> 0
typeid(*p) == typeid(derived) -> 1
```

> 多态场景下 `*p` 代表运行时实际类型。

### 类型转换
| 转换类型 | 使用场景 |
| --- | --- |
| 基本数据类型 | 隐式转换、显式转换 |
| 自定义数据类型 | 显式转换 |

#### 隐式类型转换
自动类型转换，编译器自动执行的类型转换，通常是将一种较小的数据类型转换为较大的数据类型，以避免数据丢失或精度损失。

```c++
int x = 10;
double y = x; // 隐式类型转换，int 转换为 double
```

在多态场景下，也可以使用隐式类型转换将派生类对象或指针转换为父类型，但是如果要访问派生类的特有的成员函数或字段时需要使用显式类型转换。

```c++
#include <iostream>
#include <typeinfo>

class Base {
public:
     virtual void show() {
          std::cout << "Base class" << std::endl;
     }
};

class Derived : public Base {
public:
     void show() override {
          std::cout << "Derived class" << std::endl;
     }

     void additionalFunction() {
          std::cout << "Additional function in Derived" << std::endl;
     }
};

int main() {
     Base* basePtr = new Derived; // 派生类指针赋给基类指针

     // 调用基类成员函数，会调用派生类的重写版本
     basePtr->show(); // 输出 "Derived class"

     // 无法直接调用派生类特有的成员函数，需要进行类型转换
     // Derived* derivedPtr = basePtr; // 错误，不能直接将基类指针赋给派生类指针

     // 正确的方式：使用 dynamic_cast 进行类型转换
     Derived* safeDerivedPtr = dynamic_cast<Derived*>(basePtr);
     if (safeDerivedPtr) {
          safeDerivedPtr->additionalFunction(); // 调用派生类特有的成员函数
     }

     // 只有在明确数据类型时可以使用强制类型转换
     if (typeid(*basePtr) == typeid(Derived))
     {  
          Derived* unsafeDerivedPtr = (Derived*)basePtr;
          if (unsafeDerivedPtr) {
               unsafeDerivedPtr->additionalFunction(); // 调用派生类特有的成员函数
          }
          delete unsafeDerivedPtr;
     }

     delete safeDerivedPtr;
     return 0;
}
```

#### 显式类型转换
**`1. 强制类型转换（C 风格的类型转换，不推荐）：`**
只有在明确数据类型时使用强制类型转换，不然转换失败会抛出错误。
```c++
double pi = 3.14159265359;
int x = (int)pi; // C风格的类型转换，将double转换为int
```

**`2. 静态转换：`**
静态类型转换是最基本的类型转换方式。在静态类型转换中，编译器在编译时就能够确定类型的安全性。
关键字：`static_cast`
```c++
double pi = 3.14159265359;
int x = static_cast<int>(pi); // 使用static_cast将double转换为int
```
**`3. 动态转换：`**
动态类型转换通常用于多态场景下类层次间的向下转型，即将父类指针或引用转换为子类指针或引用。动态转换在运行时检查类型的信息，只有在安全的情况下才会进行转换，所以需要判断转换结果。
关键字：`dynamic_cast`
```c++
 Derived* safeDerivedPtr = dynamic_cast<Derived*>(basePtr);
 if (safeDerivedPtr) {
      safeDerivedPtr->additionalFunction(); // 调用派生类特有的成员函数
 }
```
**`4. 常量修饰符的添加或删除：`**
常量类型转换用于添加或去除表达式的常量性。它主要用于去除对象的 `const` 属性或者添加 `const` 属性。
关键字：`const_cast`
```c++
const int* ptr = const_cast<const int*>(&x); // 去除或添加const修饰符
```

## 字符串
`C++` 提供了以下两种类型的字符串表示形式：

* `C` 风格字符串
* `C++` 引入的 `string` 类型

> 注意：字符串字面量为字符数组类型；

### C 风格字符串
`C` 风格的字符串起源于 `C` 语言，并在 `C++` 中继续得到支持。实际上是使用 `null` 字符 `\0` 终止的一维字符数组。

```c++
char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'};
```
等于：
```c++
// 长度为 7，默认在尾部添加 `\0` 字符
char site[] = "RUNOOB";
```
等于：
```c++
const char * site = "RUNOOB";
```

**`示例`**：

```c++
#include <iostream>
using namespace std;
int main ()
{
    char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'};
    cout << site << endl; //输出：RUNOOB
    cout << site[2] << endl; //输出：N
 
   return 0;
}
```
**`注意`**：

* 对于 `c++` 来说，数组名代表数组首元素地址，`char` 类型的数组可以使用数组名输出整个字符串，其他数据类型数组使用数组名的方式输出时只能输出首元素地址;
* 只有在初始化时才可以使用`""`（双引号字符串）的方式赋值，不然会报错，对于 `char []` 和 `char *` 都适用；
* 使用 `""` 为 `char *` 类型赋值时必须添加 `const` 关键字；

#### 头文件 cstring
头文件：`cstring`提供操作 `C` 风格字符串的函数。

* `strcpy(s1, s2)`：复制字符串 s2 到字符串 s1。
* `strcat(s1, s2)`：连接字符串 s2 到字符串 s1 的末尾。
* `strlen(s1)`：返回字符串 s1 的真实长度。
* `sizeof()`：获取字符数组所占用内存长度。
* `strcmp(s1, s2)`：如果 s1 和 s2 是相同的，则返回 0；如果 s1<s2 则返回值小于 0；如果 s1>s2 则返回值大于 0。
* `strchr(s1, ch)`：返回一个指针，指向字符串 s1 中字符 ch 的第一次出现的位置。
* `strstr(s1, s2)`：返回一个指针，指向字符串 s1 中字符串 s2 的第一次出现的位置。

**`示例`**：
```c++
#include <iostream>
#include <cstring>  // C 风格字符串处理函数

int main() {
    char str1[] = "Hello";
    char str2[10];

    std::strcpy(str2, str1);  // 复制字符串
    std::cout << str2 << std::endl;  // 输出: Hello

    std::cout << "Length: " << std::strlen(str1) << std::endl;  // 获取长度
}
```

#### `\0`问题
> 字符 `'\0'` 为字符串结束标志。

使用下面方式赋值字符数组时，系统会自动在字符串的末尾加上字符串结束符，即 `'\0'`。
```c++
#include <iostream>
using namespace std;
 
int main ()
{
    char str[] = "abc";
    // 输出：sizeof(str) : 4
    cout << "sizeof(str) : " << sizeof(str) << endl;
    return 0;
}
```

字符数组初始化时系统会为未初始化的元素赋值为 `\0`。
```c++
char str[5] = "abc";
char str[5] = {'a','b','c','\0','\0'};
```

#### char * vs char []

```c++
const char * site1 = "RUNOOB";
char site2[] = "RUNOOB";
```

**`相同点`**：

`site1`、`site2` 都代表字符串首地址；

**`不同点`**：
[char *a 与char a\[\] 的区别](https://blog.51cto.com/u_12468355/3402557)

1. **”读“ ”写“ 能力**
* `site1`：此时"abcd"存放在常量区。通过指针只可以访问字符串常量，而不可以改变它。
* `site2`：此时 "abcd"存放在栈。可以通过指针去访问和修改数组内容。

2. **赋值时刻**
* `site1`：是在编译时就确定了（因为是常量）。
* `site2`：在运行时确定。

3. **存取效率**
* `site1`：存于静态存储区，较慢。
* `site2`：存于栈上，较快。

### c++ string 

`std::string` 是 `C++` 标准库提供的字符串类，封装了 `C` 风格字符串，并提供 更安全、功能更强大的接口。

```c++
#include <string>
```

#### 常用函数

| 方法 |说明  |
| --- | --- |
| s.length() | 获取字符串长度 |
| s.empty() | 判断字符串是否为空 |
| s.append(s2) 或 s += s2 | 追加字符串 |
| s.substr(pos, len) | 截取子串 |
| s.find(s2) | 查找子串位置 |
| s.replace(pos, len, s2) | 替换子串 |
| s.c_str() | 转换为 C 风格字符串（char*） |

**`示例`**：
```c++
#include <iostream>
#include <string>

int main() {
    std::string str1 = "Hello";
    std::string str2 = str1;  // 直接赋值
    std::cout << str2 << std::endl;  // 输出: Hello

    str2 += " World";  // 追加字符串
    std::cout << str2 << std::endl;  // 输出: Hello World

    std::cout << "Length: " << str2.length() << std::endl;  // 获取长度
}
```

### 字符串判空

* `string`：可以使用 `length()、size()` 判断长度是否为 `0`，或直接使用 `empty()` 函数。
* `char[]`：可以通过判断首位是否为字符串结束符(`\0`)判断。
* `char*`：在 `char[]` 判空的基础上需要增加空指针判断。 

```c++
std::string run = "\0";
if (run.empty())
{
    std::cout << "is empty" << std::endl;
}
else
{
    std::cout << "not empty" << std::endl;
}

const char* site = run.c_str();
if (site == nullptr || site[0] == '\0')
{
    std::cout << "is empty" << std::endl;
}
else
{
    std::cout << "not empty" << std::endl;
}
```

```c++
#include <iostream>

int main() {

}
```

## 格式占位符

[格式占位符](https://blog.csdn.net/myth1991x/article/details/77646687)

`%d, %i`：代表整数
`&ld`：代表长整型，Linux_64系统
`%lld`：代表长整型，Windows_64系统
`%PRID64`：代表长整型，跨平台；其它还有`%PRID32`、`%PRID16`、`%PRID8`
`%f`：浮点
`%s`：字符串
`%c`：char
`%p`：指针
`%fL`：长log
`%e`：科学计数
`%g`：小数或科学计数。
`%a,%A`：读入一个浮点值(仅C99有效)。
`%c`：读入一个字符。
`%d`：读入十进制整数。
`%i`：读入十进制，八进制，十六进制整数。
`%o`：读入八进制整数。
`%x,%X`：读入十六进制整数。
`%s`：读入一个字符串，遇空格、制表符或换行符结束。
`%f,%F,%e,%E,%g,%G`：用来输入实数，可以用小数形式或指数形式输入。
`%p`：读入一个指针。
`%u`：读入一个无符号十进制整数。
`%n` 至此已读入值的等价字符数。
`%[]` 扫描字符集合。
`%%` 读 % 符号
