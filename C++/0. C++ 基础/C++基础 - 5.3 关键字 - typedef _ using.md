## 基础
### 定义
`typedef` 用于为已有类型定义别名。

### 用法
```c++
typedef oldName newName
```

示例：
```c++
#include <stdio.h>
 
int main( )
{
	typedef int INTEGER;
	INTEGER a, b;
	a = 1;
	b = 2;
	printf("%d, %d", a, b);
 
	return 0;
}
```

给`数组`、`指针`、`结构体`等类型定义别名：
数组：
```c++
// char [20] 的别名，它是一个长度为 20 的数组类型
typedef char ARRAY20[20];
```
指针：
```c++
// int 型指针的别名
typedef int * PINT；
```
结构体：
```c++
// 结构体 Books 的别名
typedef struct
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
} Book;
```
函数：
```c++
#include<iostream>
using namespace std;
typedef int (FUNC)(int, int);

FUNC add;
int main()
{
    cout << add(1, 2) << endl;
    return 0;
}
int add(int a, int b)
{
    return a + b;
}
```
函数指针：
```c++
#include<iostream>
using namespace std;
typedef int (*FUNC_P)(int, int);

int add(int a, int b)
{
    return a + b;
}
int sub(int a, int b)
{
    return a - b;
}
int main()
{
    FUNC_P p = add;
    cout << p(1, 2) << endl;
    p = sub;
    cout << p(1, 2) << endl;
    return 0;
}
```

## using
`using` 关键字有三种用法：

* **导入命名空间**
* **在派生类中引用基类成员**
* **指定别名**

### 导入命名空间
使用 `C++` 在写不同的功能模块时，为了防止命名冲突，建议对模块取命名空间，这样在使用时就需要指定是哪个命名空间。

使用 `using` 导入命名空间，即使一个命名空间中的所有名字都在该作用域中可见，常见的如下：

```c++
// 导入整个命名空间到当前作用域
using namespace std;

// 只导入某个变量到当前作用域 
using std::cout; 
```

> `注意`：在头文件中，一般不应该使用 `using` 声明。因为头文件的内容会拷贝到所有引用它的文件中去，如果头文件里有某个 `using` 声明，那么每个使用了该头文件的文件就都会有这个声明，从而可能产生名字冲突。

### 继承体系中，改变部分接口的继承权限
有这样一种应用场景，比如我们需要私有继承一个基类，然后又想将基类中的某些 `public` 接口在子类对象实例化后对外开放直接使用。如下即可
```c++
#include <iostream>

using namespace std;

class Base
{
public:
     Base(){}
     ~Base(){}

     void dis1()
     {
          cout<<"dis1"<<endl;
     }
     void dis2()
     {
          cout<<"dis2"<<endl;
     }
};

class Derived : private Base
{
public:
     //需要在BaseA的public下释放才能对外使用
     using Base::dis1;
     void dis2show()
     {
          this->dis2();
     }
};

int main(int argc, char *argv[])
{

    Derived d;
    d.dis1();
    d.dis2show();

    return 0;
}
```

### 指定别名
`using` 完全可以替代 `typedef` 用于指定别名，并且 `using` 可以用来为模板类设置别名，而 `typedef` 不可以。目前推荐使用 `using`，更加清晰易懂。

**`格式`**：
```c++
// 定义变量别名
using newname = oldname;
// 定义函数别名
using new_fun_name = void(const std::string&);
// 定义指针函数别名
using new_fun_name_ptr = void(*)(const std::string&);
```

**`示例`**：
```c++
#include <iostream>

// 定义两个函数，分别实现加法和减法
int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

// 定义一个函数指针类型别名
using OperationFunction = int(*)(int, int);

// 定义一个函数，接受一个函数指针和其他参数作为参数
int operate(OperationFunction operation, int a, int b, bool verbose) {
    if (verbose) {
        std::cout << "Operation is ";
        if (operation == add) {
            std::cout << "addition." << std::endl;
        } else if (operation == subtract) {
            std::cout << "subtraction." << std::endl;
        }
    }
    return operation(a, b); // 根据传入的函数指针选择调用相应的函数
}

int main() {
    // 使用 using 定义的函数指针别名
    int result1 = operate(add, 5, 3, true);       // 调用 add 函数，结果为 8
    int result2 = operate(subtract, 5, 3, false); // 调用 subtract 函数，结果为 2

    std::cout << "Result of adding: " << result1 << std::endl;
    std::cout << "Result of subtracting: " << result2 << std::endl;

    return 0;
}
```

```c++
#include <iostream>
#include <string>

// 定义一个普通函数
void greet(const std::string& name) {
    std::cout << "Hello, " << name << "!" << std::endl;
}

// 使用 using 定义函数类型别名
using GreetFunction = void(const std::string&);

// 接受函数指针参数的函数
void callGreetFunction(GreetFunction greeter, const std::string& name) {
    // 调用函数指针来执行 greet 函数
    greeter(name);
}

int main() {
    // 声明一个函数指针变量，并将函数名赋值给它
    GreetFunction* greeter = greet;
    // 调用接受函数指针参数的函数，并传递函数指针作为参数
    callGreetFunction(greet, "world");

    return 0;
}
```

## typedef vs #define
一、作用时间不同：

* `#define`：预处理阶段。
* `typedef`：编译阶段。

二、功能差异：

* `#define`：不只是可以为类型取别名，还可以定义常量、变量、编译开关等。
* `typedef`：用来定义类型的别名，定义与平台无关的数据类型，与 struct 的结合使用等。

三、作用域不同：

* `#define`：没有作用域和访问权限的限制，只要之前预定义过宏，就可以使用。
* `typedef`：有作用域和访问权限的限制。

四、指针操作：
```C++
typedef int * pint;
#define PINT int *
 
int i1 = 1, i2 = 2;
 
const pint p1 = &i1;	//p不可更改，p指向的内容可以更改，相当于 int * const p;
const PINT p2 = &i2;	//p可以更改，p指向的内容不能更改，相当于 const int *p；或 int const *p；
 
pint s1, s2;	//s1和s2都是int型指针
PINT s3, s4;	//相当于int * s3，s4；只有一个是指针。
```

## 函数指针
函数指针是指向函数的指针变量。和变量一样，函数在内存中有固定的地址。函数的实质也是内存中一块固定的空间。

* **作为函数参数传递**：函数指针可以作为参数传递给其他函数，使得函数的行为可以在运行时动态确定。这种方式通常用于实现回调机制，让函数能够根据需要调用不同的回调函数。
* **动态选择调用的函数**：通过函数指针可以在运行时选择调用的函数。这在某些情况下非常有用，例如根据条件选择不同的处理函数或实现动态派发。
* **实现函数指针数组**：函数指针可以组成函数指针数组或函数指针表，用于根据索引或条件动态调用不同的函数。
* **实现函数映射表**：函数指针可以用于实现函数映射表，将字符串或其他标识符映射到对应的函数上，实现动态调用。
* **实现函数工厂**：通过函数指针可以实现函数工厂模式，根据参数动态创建并返回不同的函数。
* **实现函数的延迟绑定**：函数指针允许延迟绑定到具体的函数，直到运行时才确定要调用的函数。
