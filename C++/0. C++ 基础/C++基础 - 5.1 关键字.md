## explicit
[C++ explicit关键字详解](https://www.cnblogs.com/rednodel/p/9299251.html)
`explicit` 关键字只能用于修饰只有一个参数的类构造函数, 它的作用是表明该构造函数是显示的, 而非隐式的。跟它相对应的另一个关键字是 `implicit`, 意思是隐藏的,类构造函数默认情况下即声明为 `implicit`(隐式).

`explicit` 关键字的作用就是防止类构造函数的隐式自动转换。根据查询的资料来看使用 `explicit` 关键字的作用主要是在初始化类对象不允许使用隐式转换，时让代码看起来更清晰，至于有没有避免一些隐藏的问题还没有看到具体的例子。

```c++
class MyObject
{
public:
    explicit MyObject(int value);
    int32_t length;
};

MyObject::MyObject(int value) {
    length = value;
}
```

当不声明构造函数为显示的时：
```c++
// 正常
MyObject my_object1(10);
// 正常
MyObject my_object2 = 20;
```

当声明为显示构造函数时：
```c++
// 正常
MyObject my_object1(10);
// error
MyObject my_object2 = 20;
```

## std::ref
`C++11` 中引入 `std::ref` 用于取某个变量的引用。

`std::ref` 是 `C++` 标准库中的一个函数模板，定义在 `<functional>` 头文件中。如果已引入的头文件无法找到那可以主动引入 `<functinal>` 头文件。
```c++
#include <functinal>
```

```c++
#include <thread>
#include <iostream>
#include <string>

void threadFunc(std::string &str, int a)
{
    str = "change by threadFunc";
    a = 13;
}

int main()
{
    std::string str("main");
    int a = 9;
    std::thread th(threadFunc, str, a);

    th.join();

    std::cout<<"str = " << str << std::endl;
    std::cout<<"a = " << a << std::endl;

    return 0;
}
```
这样是编译不通过的，需要使用 `std::ref()` 提取变量 `a` 的引用传入线程构造函数。

```c++
...
std::thread th(threadFunc, std::ref(str), a);
...
```

## default、delete
[C++随笔：关键字 =default 和 =delete](https://zhuanlan.zhihu.com/p/430916670)

`default`：如果对构造函数进行了重载，则编译器不会隐式的生成一个默认的构造函数，此时如果调用了默认构造函数会在编译时报错，为了避免这种情况，一般会选择重写默认构造函数，且函数体为空。关键字 `=default` 优化了这种行为，用该关键字标记重写的默认拷贝构造函数，编译器会隐式生成一个版本，在代码更加简洁的同时，编译器隐式生成的版本的执行效率更高。

```c++
class Mine 
{
public:
    // 重载构造函数，此时不会隐式生成默认构造函数 
    Mine(int num) {}
    
    // 方式一：重写默认构造函数，
    // 需要在源文件中定义
    Mine() {}
    
    // 方式二：关键字 =default 标记编译器隐式生成该类的默认构造函数，
    // 无需在源文件中定义
    Mine() = default;
};
```

> **`注意`**：使用 `default` 关键字声明的默认构造函数不需要在源文件中定义。

`delete`：对于拷贝构造函数和移动构造函数不论有没有对它们进行重载，编译器始终会隐式生成默认版本，但有的时候不希望类实例进行拷贝构造或拷贝赋值，此时可以重写它们并将权限设置为 `private`，但这样只是利用语法特性来碰巧实现效果，且对友元会带来困惑。可以使用关键字 `=delete` 标记不想被类实例调用的拷贝构造和拷贝赋值，相当于删除了它们。

```c++
class Mine
{
public:
    // 保证重载了构造函数后，编译器会隐式生成一个默认版本 
    Mine() = default;
    // 禁止使用拷贝构造函数和移动构造函数
    Mine(const Mine& ob) = delete;
    Mine(const Mine&& ob) = delete;
    Mine& operator=(const Mine& ob) = delete;
    Mine& operator=(Mine&& ob) = delete;
};
```
> **`注意`**：`operator=` 代表的赋值运算符，等号两边不添加空格。
