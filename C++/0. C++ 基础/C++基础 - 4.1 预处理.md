# 什么是预处理
预处理是指在编译前需要完成的工作。
常见的预处理指令：

* `#include`
* `#define`、`#undef`
* `#ifndef`、`#ifdef`、`#endif`
* `#if`、`#else`、`#endif`

## #include
用于把头文件拷贝到源文件中。

## #define、#undef
- `#define`：预定义符号常量；
- `#undef`：取消预定义符号常量；

```c++
#define PI 3.14159
```

### 带参数的宏
```c++
#define MIN(a,b) (a<b ? a : b)
...
int i = 100;
int j = 30;
printf("较小的值为：%d", MIN(i, j));

结果：
printf("较小的值为：%d", (i<j ? i : j));
较小的值为：30
```

### 特殊符号
宏定义中：
`#`：符号右侧参数加双引号转为字符串形式；
`##`：拼接符号左右两侧参数；

```c++
#include<cstdio>
#define STR(s) #s
#define CONS(a, b) a##b
using namespace std;
int main()
{
    int ab = 100;
    printf("%s\n", STR(ab)); //输出 ab
    printf("%d\n", CONS(a, b)); //输出 100
    return 0;
}
```
等价于：
```c++
#include<cstdio>
#define STR(s) #s
#define CONS(a, b) a##b
using namespace std;
int main()
{
    int ab = 100;
    printf("%s\n", "ab");
    printf("%d\n", ab);
    return 0;
}
```

## 条件编译

宏定义判断：
* `#ifndef`
* `#ifdef`
* `#endif`

**`示例`**：
```c++
#ifdef SOMETHING
int func1(){/*...*/}
#else
int func1(){/*...*/}
#endif
```

条件判断：
* `#if`
* `#else`
* `#endif`

```c++
#define  A 0  //把A定义为0
#if (A > 1)
    printf("A > 1");  //编译器没有编译该语句,该语句不生成汇编代码
#elif (A == 1)
    printf("A == 1"); //编译器没有编译该语句,该语句不生成汇编代码
#else
    printf("A < 1");   //编译器编译了这段代码，且生成了汇编代码，执行该语句
#endif

```

### 头文件保护

防止同一个头文件被多次引用

```c++
#ifndef SOMETHING
#define SOMETHING
文件正文
#endif
```

其他方式(在文件开头位置)：

* `#pragma once`
* `_Pragma("once")`

```c++
#pragma once

文件正文
```

### #ifdef vs #if
- `#ifdef`：只关心宏是否定义；
- `#if`：宏是否定义且宏的逻辑真假；

## 内置宏

| 宏 | 说明 |
| --- | --- |
| __DATE__ | 程序最后编译日期宏 |
| __TIME__ | 程序最后编译时间宏 |
| __LINE__ | 当前行数宏 |
| __FILE__ | 当前运行文件名宏 |
| __FUNCTION__ | 当前运行函数宏 |
| __func__ | 当前运行函数宏 |
