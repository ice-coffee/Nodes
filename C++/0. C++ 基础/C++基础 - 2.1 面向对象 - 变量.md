## 变量分类
- 全局变量：文件最外层定义的变量；
- 成员变量：类中定义在函数或代码块外的变量；
- 局部变量：函数或代码块中定义的变量；

> **`注意`**：成员变量不可在定义类时赋值。

### 初始化
- 全局变量：系统自动初始化；
- 成员变量：构造函数初始化 / 初始化列表；
- 局部变量：主动初始化；

### 作用
- 全局变量：全局变量需在一个头文件中声明，在所引用的源文件中定义；
- 成员变量：~；
- 局部变量：~；

[C++ const 关键字小结](https://www.runoob.com/w3cnote/cpp-const-keyword.html)

### 类成员变量默认值
* **内置类型的成员变量**：例如，`int`、`double`、`char` 等内置类型，如果你在类的构造函数中没有初始化这些成员变量，它们将拥有未定义的值，其值不可预测。

* **指针类型的成员变量**：指针类型的成员变量（如 `int*`、`char*`）也遵循同样的规则。如果没有显式初始化，它们将指向随机的地址，可能会导致程序崩溃或不安全的行为。

* **用户自定义类型的成员变量**：如果类的成员变量是一个用户自定义类型（比如另一个类的实例），那么这些成员变量的构造函数将会被自动调用。如果该类有默认构造函数，则会使用默认构造函数初始化成员变量。如果没有默认构造函数，编译时会报错。

* **静态成员变量**：静态成员变量不会由类的构造函数初始化，它们必须在类的外部显式初始化。

* 从 `C++11` 开始，可以在声明时为成员变量赋予默认值。

## const

### 1. 修饰变量

#### 1.1 初始化

- **全局常量**：显示初始化；
- **类常量**：可在声明时初始化或使用初始化列表初始化；
- **函数常量**：显示初始化；

#### 1.2 修饰普通变量

被 `const` 修饰的变量，其值不可改变。也就是说不可以使用赋值运算符（`=`）对其重新赋值。

#### 1.3 修饰指针变量

`const` 修饰指针变量时采用 `就近原则`（自己总结的，方便记忆）：

**`const int *p`**：修饰 `*p` --> 左定值；
**`int *const p`**：修饰 `p` --> 右定向；

##### 1.3.1 左定值

**`左定值`**：`const` 位于 * 号的左边，表示 `const` 修饰指针指向的内容，其内容不可改变。

```c++
const int *p = 8;
```

**`示例`**：

```c++
#include <iostream>
#include <string>
 
using namespace std;

int main ()
{
    const int *p = new int(10);
    cout << *p <<endl;
    // error: read-only variable is not assignable
    *p = 11;
    cout << *p <<endl;
    p = new int(12);
    cout << *p <<endl;

    return 0;
}
```

##### 1.3.2 右定向
**`右定向`**：`const` 位于 * 号的右边，表示 `const` 修饰指针，指针变量指向的地址不可改变。

```c++
int a = 8;
int *const p = &a;
*p = 9; // 正确
int b = 7;
p = &b; // 错误
```

**`示例`**：

```c++
#include <iostream>
#include <string>
 
using namespace std;

int main ()
{
    int *const p = new int(10);
    cout << *p <<endl;
    *p = 11;
    cout << *p <<endl;
    // error: cannot assign to variable 'p' with const-qualified type 'int *const'
    p = new int(12);
    cout << *p <<endl;

    return 0;
}
```

#### 1.4 修饰引用变量

引用变量作为源变量的别名，`const` 修饰引用变量和修饰普通变量作用一致，不可重新赋值。
`const` 修饰引用变量仅一种形式就是在 `&` 左侧。

```c++
int a = 10;
const int &v1 = a;
```

### 2. 修饰函数

#### 2.1 在函数名前

**`语法`**：

```c++
const int* fun()
```

**`作用`**：

**修饰返回值**，`const` 放在函数前表示返回一个 `const` 的值，不允许修改。

#### 2.2 在函数名后

**`语法`**：

```c++
void fun() const
```

**`作用`**：

**修饰函数**，防止修改当前调用成员函数的类对象的成员。

**`示例`**：

```c++
#include<iostream>
 
using namespace std;

class A
{
public:
    int value;
    void fun() const
    {
        // 编译失败：cannot assign to non-static data member within const member function 'fun'
        value = 100;
    };
};

int main(void)
{
    A a;
    a.fun();
    cout<<a.value<<endl;
    return 0;
}
```

**`原理`**：

[梳理c++ const 修饰函数](https://zhuanlan.zhihu.com/p/110159656)

```c++
#include<iostream>

using namespace std;

class A
{
private:
    int data;
public:
    A(int num):data(num){}
    ~A(){};
    int& get_data()
    {
        return data;
    }
};

int main()
{
    const A a(1);
    // 编译失败：'this' argument to member function 'get_data' has type 'const A', but function is not marked const
    a.get_data();
    return 0;
}
```

任何成员函数都含有一个隐式的 `this` 指针参数，它指向当前调用函数的对象。`const` 修饰成员函数，根本上是修饰了 `this` 指针。`const` 成员函数可以被 `const` 和非 `const` 对象只能调用，非 `const` 成员函数只能被 `non-const` 对象调用。

所以 `const` 关键字在函数名后时不能与 `static` 关键字同时使用，因为 `static` 关键字修饰静态成员函数，静态成员函数不含有 `this` 指针，即不能实例化，`const` 成员函数必须具体到某一实例。

**`注意`**：

可以在 `const` 修饰的成员函数中修改 `static` 静态成员变量的值，因为静态成员变量不属于任意一个对象。

#### 2.3 mutable

**`作用`**：

被 `mutable` 修饰的成员可以处于不断变化中，可以在 `const` 修饰的成员函数中修改被 `mutable` 修饰的成员函数。

**`示例`**：

```c++
#include<iostream>
 
using namespace std;

class A
{
public:
    mutable int value;
    void fun() const
    {
        value = 100;
    };
};

int main(void)
{
    A a;
    a.fun();
    cout<<a.value<<endl;
    return 0;
}

// 输出
100
```

- `#define` 预处理器：
    - 形式：`#define` 标识符 值

## final
[关键字 final 的用法](https://www.cnblogs.com/CooCoChoco/p/12596228.html)

**`注意`**：

* `C++` 中的 `final` 是 `C++11` 新增；
* `final` 只能修饰**类**与**虚函数**，无法修饰普通成员函数，也无法修饰变量;

**`作用`**：

* 修饰类，让类无法被继承；
* 修饰类的虚函数，让虚函数在子类中不能被重写；

**`示例`**：
```c++
// 修饰类
class A final {};

// 修饰虚函数
virtual void show() final {};
```

## static
### 修饰变量
#### 初始化

- **静态全局变量**：系统自动初始化；
- **静态成员变量**：只能在类的内部声明，定义必须在类定义体的外部，若定义时不主动初始化，系统自动赋初始值；
- **静态局部变量**：必须显示初始化，且仅能初始化一次；

#### 作用
- **静态全局变量**：只能作用于定义它的文件里，不能作用到其它文件里；
- **静态成员变量**：在多个类对象间共享数据；
- **静态局部变量**：仅初始化一次，自第一次被初始化直到程序运行结束都一直存在；且静态局部变量的初始化是线程安全的。

> `static` 修饰的变量其实都是仅初始化一次，局部因为变量默认是每次调用重建的，而 `static` 局部变量突然变成只初始化一次，所以才进行特别强调。

静态成员变量：
```c++
#include <iostream>
using namespace std;

class Test {
public:
    static int a;
    static int b;
    static int c;
};

// 定义静态成员变量
int Test::b;
int Test::c = 10;

int main ()
{
	Test test = Test();
	// undefined reference to `Test::a'
	cout<<test.a<<endl;
	// 输出 0 
	cout<<test.b<<endl;
	// 输出 10 
	cout<<test.c<<endl;
 
	return 0;
}
```

对于静态成员变量仅初始化一次的示例说明：

```c++
class Config{
public:
    static bool initialize(){
        if(!get_is_init()){
            get_is_init() = true;
        }
        return true;
    }

private:
    static bool& get_is_init(){
        // 局部静态变量，仅调用时初始化一次，重复调用
        static bool _is_init = false;
        return _is_init;
    }
};
```

### 修饰函数

#### 静态全局函数
静态全局函数只能在文件所在的编译单位内使用，不能在其它编译单位内使用。

#### 静态成员函数
[C++ static静态成员函数详解](http://c.biancheng.net/view/2228.html)
静态成员函数与普通成员函数的根本区别在于：普通成员函数有 `this` 指针，可以访问类中的任意成员；而静态成员函数没有 `this` 指针，只能访问静态成员（包括静态成员变量和静态成员函数）。

> 注意：静态成员函数在声明时要加 static，在定义时不能加 static。

**`声明`**：
```c++
class A{
public:  //声明静态成员函数
    static int getValue();
};
```

**`定义`**：
```c++
//定义静态成员函数
int Student::getValue(){
    return 0;
}
```

### 扩展
#### const 和 static 同时修饰变量时的声明和初始化
`const` 修饰变量初始值：声明时初始化或初始化列表中初始化。
`static` 修饰变量初始化：只能在定义时初始化。

`const static` 修饰变量时有两种初始化方式：

* 变量声明时初始化
* 在类定义体外部初始化

```c++
#include <iostream>
#include <string>
using namespace std;

class A
{
private:
	/* data */
public:
	const static int num1; //声明
	const static int num2 = 13; //声明和初始化
};

const int A::num1 = 2; //定义和初始化

int main()
{
	cout << A::num1 << endl;
	cout << A::num2 << endl;
	return 0;
}
```

#### extern（存疑）
使用上面示例测试，在未使用 `include` 语句的情况下可以在其他编译单元通过 `extern` 关键字声明静态全局变量并使用，且内存地址一致。
