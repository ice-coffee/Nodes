## virtual 关键字
用于修饰函数，表明此函数在调用时可以根据所调用的对象类型来选择调用的函数，这种操作被称为`动态链接`或后期绑定。c++规定，当一个成员函数被声明为虚函数后，其派生类中的同名函数都自动成为虚函数。因此，在子类重新声明该虚函数时，可以加，也可以不加，但习惯上每一层声明函数时都加 `virtual`,使程序更加清晰。

**`虚函数 vs 纯虚函数`**

* **虚函数**：virtual 函数返回类型 函数名(参数表) {函数体}；
* **纯虚函数**：virtual 返回值 函数名(参数表) = 0；

**`示例`**：

```c++
// 虚函数
virtual void method()
{
    cout << "method" <<endl;
}

// 纯虚函数
virtual void method() = 0;
```

**`使用`**：

* `public` 或 `protected` 修饰的成员函数：声明为虚函数则实现类中可以重写此函数实现多态；
* 析构函数：声明为虚函数后，在多态场景下，当 `delete` 对象时，会先调用派生类的析构函数然后再调用基类的析构函数。否则只会调用基类析构函数；

**`示例`**：

```c++
#include <iostream>  
using namespace std;
class Base
{
public:
	virtual void who()
	{
		cout << "I am Base" <<endl;
	}
	virtual ~Base() {
		cout << "Base 析构" <<endl;
	}
};
class Derived : public Base
{
public:
	void who()  // 不写inline时隐式内联
	{
		cout << "I am Derived" <<endl;
	}
	
	~Derived() {
		cout << "Derived 析构" <<endl;
	}
};

int main()
{ 
	Base *ptr = new Derived();
	ptr->who();
	
	delete ptr;
	ptr = nullptr;

	return 0;
} 

//输出
I am Derived
Derived 析构
Base 析构
```

### 抽象类
在 `C++` 中，如果一个类包含至少一个纯虚函数，那么这个类就是抽象类。

**特点**：

1. **不能实例化；**
2. **必须被派生类继承并实现纯虚函数；**
3. **可以定义指针或引用；**

**作用**：

1. **定义接口**：抽象类可以定义一组接口（纯虚函数），要求所有派生类必须实现这些接口。
2. **实现多态**：通过基类指针或引用调用派生类的实现，实现运行时多态。
3. **代码复用**：抽象类可以包含一些非纯虚函数或成员变量，供派生类复用。

**示例**：
```c++
#include <iostream>

// 抽象类
class Shape {
public:
    virtual double area() const = 0; // 纯虚函数
    virtual void print() const {
        std::cout << "This is a shape." << std::endl;
    }

    // 添加虚析构函数
    virtual ~Shape() {
        std::cout << "Shape destructor called." << std::endl;
    }
};

// 派生类：圆形
class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}

    double area() const override {
        return 3.14159 * radius * radius;
    }

    void print() const override {
        std::cout << "This is a circle with area: " << area() << std::endl;
    }

    // 派生类析构函数
    ~Circle() {
        std::cout << "Circle destructor called." << std::endl;
    }
};

// 派生类：矩形
class Rectangle : public Shape {
private:
    double width, height;
public:
    Rectangle(double w, double h) : width(w), height(h) {}

    double area() const override {
        return width * height;
    }

    void print() const override {
        std::cout << "This is a rectangle with area: " << area() << std::endl;
    }

    // 派生类析构函数
    ~Rectangle() {
        std::cout << "Rectangle destructor called." << std::endl;
    }
};

int main() {
    Shape* shape1 = new Circle(5.0);
    Shape* shape2 = new Rectangle(4.0, 6.0);

    shape1->print(); // 输出: This is a circle with area: 78.5397
    shape2->print(); // 输出: This is a rectangle with area: 24

    delete shape1; // 正确调用 Circle 的析构函数
    delete shape2; // 正确调用 Rectangle 的析构函数

    return 0;
}
```

## 继承

> **`语法`**：class derived-class: access-specifier base-class



```c++
class Base {
};

class Derived : public Base {
};
```

### 访问修饰符
| 访问 | public | protected | private |
| --- | --- | --- | --- |
| 同一个类 | yes | yes | yes |
| 派生类 | yes | yes | no |
| 外部的类 | yes | no | no |

一个派生类继承了所有的基类方法，但下列情况除外：

* 基类的构造函数、析构函数和拷贝构造函数。
* 基类的重载运算符。
* 基类的友元函数。

### 继承类型
* **公有继承（public）**：当一个类派生自公有基类时，基类的公有成员也是派生类的公有成员，基类的保护成员也是派生类的保护成员，基类的私有成员不能直接被派生类访问，但是可以通过调用基类的公有和保护成员来访问。
* **保护继承（protected）**： 当一个类派生自保护基类时，基类的公有和保护成员将成为派生类的保护成员。
* **私有继承（private）**：当一个类派生自私有基类时，基类的公有和保护成员将成为派生类的私有成员。

### 多继承
**`语法`**：
```c++
class <派生类名>:<继承方式1><基类名1>,<继承方式2><基类名2>,…
{
<派生类类体>
};
```

**`示例`**：
```c++
class Dog: public Animal, public Hair 
{
    ......
}
```

### 虚继承
**`场景`**：类 `A` 派生出类 `B` 和类 `C`，类 `D` 继承自类 `B` 和类 `C`。

**`问题`**：派生类中会报错多份基类同名成员，产生命名冲突和数据冗余的问题。

**`示例`**：
```c++
//间接基类A
class A{
protected:
    int m_a;
};
//直接基类B
class B: public A {
protected:
    int m_b;
};
//直接基类C
class C: public A {
protected:
    int m_c;
};
//派生类D
class D: public B, public C {
public:
    void seta(int a){ m_a = a; }  //命名冲突
    void setb(int b){ m_b = b; }  //正确
    void setc(int c){ m_c = c; }  //正确
    void setd(int d){ m_d = d; }  //正确
private:
    int m_d;
};
int main(){
    D d;
    return 0;
}
```

**`虚继承改造`**：
```c++
//间接基类A
class A{
protected:
    int m_a;
};
//直接基类B
class B: virtual public A {  //虚继承
protected:
    int m_b;
};
//直接基类C
class C: virtual public A {  //虚继承
protected:
    int m_c;
};
//派生类D
class D: public B, public C {
public:
    void seta(int a){ m_a = a; }  //正确
    void setb(int b){ m_b = b; }  //正确
    void setc(int c){ m_c = c; }  //正确
    void setd(int d){ m_d = d; }  //正确
private:
    int m_d;
};
int main(){
    D d;
    return 0;
}
```

开发中，除架构设计阶段根据场景使用外，应避免使用虚继承。
