## 格式
![](https://learn.microsoft.com/zh-cn/cpp/cpp/media/lambdaexpsyntax.png?view=msvc-170)

1. `capture` 子句（在 C++ 规范中也称为 Lambda 引导。）
2. `参数列表`（可选）。 （也称为 Lambda 声明符）
3. `mutable` 规范（可选）。
4. `exception-specification`（可选）。
5. `trailing-return-type`（可选）。
6. `Lambda` 体。
