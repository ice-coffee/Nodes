## 多态
**`多态条件`**：

* 存在继承关系；
* 基类函数被重写；
* 存在基类类型`指针`或`引用`，通过该指针或引用调用虚函数；

> **`注意`**：在 `C++` 中只有虚函数才可以被重写。

**`示例`**：

```c++
#include <iostream> 
using namespace std;

class A
{
public:
    virtual void show() = 0;
};

class B : public A
{
public:
    void show()
    {
        cout<<"b - show"<<endl;
    }
};

int main(int argc, char const *argv[])
{
    A *a = new B();
    a->show(); // 输出：b - show
    return 0;
}
```
