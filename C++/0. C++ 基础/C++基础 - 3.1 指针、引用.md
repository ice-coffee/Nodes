## 指针
[C++ 指针](https://www.runoob.com/cplusplus/cpp-pointers.html)

`指针` 其值是另一个变量的内存地址。

**`指针声明`**：
```c++
type* var-name
```

> `注意：`
> 1. `var-nam` 才是指针变量。

### 指针类型

[C++中野指针和空指针和无类型指针](https://developer.aliyun.com/article/252233)

#### 野指针

**`说明`**：

所谓的野指针指的是一个指针变量指向了不可使用的内存空间。

**`产生原因`**：

- 指针变量创建时候没有被初始化：任何指针变量在创建的时候，不会自动成为NULL指针，它的默认值是随机的，因此该指针就会成为一个野指针，可能指向一块不可使用的内存空间。
- `delete` 或 `free` 指针之后没有把指针设置为 `NULL`：`delete` 和 `free` 只是把指针所指的内存空间释放掉，而没有对指针本身进行释放。
- 指针操作超过了指向内存空间的作用范围：当指针越界之后也会变成一个野指针。

#### 空指针

**`说明`**：

在指针变量声明的时候，如果没有确切的地址可以赋值，为指针变量赋一个 `NULL` 值是一个良好的编程习惯。赋为 `NULL` 值的指针被称为空指针。

`NULL` 指针是一个定义在标准库中的值为 `0` 的常量。

```c++
#include <iostream>
using namespace std;

int main ()
{
   int *ptr = NULL;
   // 输出：ptr 的值是 0
   cout<<"ptr 的值是 "<<ptr<<endl;
   return 0;
}
```

如需检查一个空指针，您可以使用 `if` 语句：

```c++
if(ptr) {} else {}
```

> `C++ 11` 提供了 `nullptr`，推荐使用 `nullptr` 而非 `NULL`。

#### 无类型指针
[C 语言中 void* 详解及应用](https://www.runoob.com/w3cnote/c-void-intro.html)

**`说明`**：

无类型指针指的是 `void*` 这种指针，表示可以指向任何数据类型。

* `void` 指针可以指向任意类型的数据，也就是说可以使用任意类型的指针对 `void` 指针赋值。
* `void` 指针赋值给其他类型指针时需要强制类型转换。
* `void` 指针不能进行任何算法运算。

**`示例`**：

```c++
#include <iostream>
using namespace std;

int main ()
{
    int n = 3;

    int* p = NULL;  //说明指针p此时空闲，没有指向任何有意义的内存空间
    void* gp = &n;  //无类型指针gp指向整型变量n
    p = (int *)gp;   //把无类型指针转换为整型指针

    cout << *p << endl;

    return 0;
}
```

#### `this` 指针
`Java` 和 `C++` 都有 `this` 指针（或关键字），用于引用当前对象的引用。虽然它们在某些方面有相似之处，但也存在一些重要的区别。

**`相同点：`**

* **引用当前对象**：在方法内部，this 指针/关键字都用于引用当前对象，即调用该方法的对象。这允许您在方法中访问和操作对象的成员变量和方法。
* **解决名称冲突**：在方法内部，如果存在局部变量和成员变量或参数与成员变量同名，使用 this 可以明确指定访问的是成员变量，而不是局部变量或参数。

**`不同点：`**

**语法：**

* `Java` 中：使用关键字 this 来引用当前对象，如 this.fieldName 或 this.methodName()。
* `C++` 中：使用指针 this 来引用当前对象，如 this->fieldName 或 this->methodName()。

**语言类型：**

* `Java` 中：this 关键字只能用于类中的方法。
* `C++` 中：this 指针可以用于类的成员函数，也可以用于类的非成员函数（友元函数）。

**空指针：**

* `Java` 中：this 关键字永远不会是空指针。如果在对象构造过程中访问 this，那么 this 会引用正在构建的对象，不会引发空指针异常。
* `C++` 中：this 指针可以为空指针。如果在对象构造过程中访问 this，那么它可能是空指针，因此在使用 this 之前通常需要检查是否为空。

### 初始化

**`初始化`**：

```c++
#include <iostream>
using namespace std;

int main ()
{
    // 野指针
    int* ptr;
    cout << "ptr 的值是 " << ptr << endl;
    // 空指针
    ptr = nullptr;
    cout << "ptr 的值是 " << ptr << endl;
    // 为指针赋值
    int a = 10;
    ptr = &a;
    cout << "ptr 的值是 " << ptr << endl;

    // 错误示例
    // ptr = 10;

    return 0;
}

输出：
ptr 的值是 0x0
ptr 的值是 0x0
ptr 的值是 0x16dd4332c
```

**`销毁`**：

[C/C++ 安全释放指针的方法](https://jidzhang.github.io/code/2015/03/10/delete-pointer-in-c-safely.html)

```c++
#include <stdio.h>
#include <stdlib.h>

#define SAFE_FREE(ptr) { free(ptr); ptr = NULL;}
#define SAFE_DEL(ptr) { delete ptr; ptr = NULL;} 
#define SAFE_DELARR(ptr) { delete [] ptr; ptr = NULL;} 

int main(int argc, char **argv) 
{ 
    char* p = new char[100]; 
    SAFE_DELARR(p); 
    //system("pause"); 
    return 0;
}
```

安全释放指针的本质就是在释放了指针后一定要及时地把指针置为 `NULL`。

### 大小
指针的大小取决于系统的体系结构。通常情况下：

* 在 32 位系统上，指针的大小通常是 4 字节。
* 在 64 位系统上，指针的大小通常是 8 字节。

### 指针运算
[C语言精要总结-指针系列](https://zhuanlan.zhihu.com/p/28163564)

指针只可以进行加、减法运算。

**`整数运算`**：

指针和整数进行加、减法运算，就是存储的地址值加上或者减去`n*`指针指向类型的空间大小。

> 结果指针 = 指针 ± n * 指针指向类型空间大小。

![](https://pic2.zhimg.com/80/v2-95a35604227274cad40b45f4a9e9afd9_1440w.png)

**`指针运算`**：

两个指针之间只可以进行减法运算，且必须是同类型的指针。运算结果为两个指针指向地址之间，可以存放多少此类型的变量数（或其相反数），类型为 `ptrdiif_t` 类型（一种有符号整数类型）。

```c++
int* p1 = (int *) 0x100;
int* p2 = (int *) 0x10c;
ptrdiff_t diff = p1 - p2;
printf("p2-p1 : %ld\n", diff); // -3
```

## 引用
[C++ 引用](https://www.runoob.com/cplusplus/cpp-references.html)

[C++ 引用的作用和用法](https://www.cnblogs.com/xiaofengkang/archive/2011/05/16/2048262.html)

`引用` 是另一个变量的别名。引用变量同和它绑定的变量具有相同的内存地址和值。

示例：
```c++
int i = 17;
int& r = i;
```
> `注意：`
> 1. 引用必须绑定到一个有效的对象（**左值**），而不能绑定到字面量（**右值**，如 10）；
> 2. `r` 才是引用变量；

## 对比
| | 初始化时机 | 申请内存 | 是否可为空 | 重新绑定 | 多态 | 是否支持字面量初始化 |
| --- | --- | --- | --- | --- | --- | --- |
| 指针 | 任何时间被初始化 | 有 | 有 | 可 | 支持 | 否 |
| 引用 | 必须在创建时被初始化 | 无 | 无 | 否 | 支持 | 否 |

### 引用变量不能重新赋值
『引用变量不能重新赋值』这句话其实正确来说应该是『引用变量不能重新**绑定**』。

这叫重新赋值：
```c++
int a = 10;
// 1. 创建引用变量并和变量 a 绑定
int& b = a;

// 2. 引用变量重新赋值，其实是对 a 的重新赋值
b = 100;
```

至于重新绑定....不会 `!^_^`。

## 使用

| 使用场景 | & | * |
| --- | --- | --- |
| 声明时使用 | 声明引用变量 | 声明指针变量 |
| 调用时使用 | 变量的地址 | 变量的值 |

在 `C++` 中指针、引用的主要作用如下：

1. **防止发生额外拷贝**（拷贝执行场景在 `类` 的章节有介绍）；
2. **想要操作原始数据**。

### 作为函数参数

* 使用指针形参表示形参可以被赋新值，且不影响实参。
* 防止实参被赋新值时，使用const修饰的引用形参。

交换 `int` 值：
```c++
#include<iostream>
using namespace std;

//引用作为函数的形参
void swap(int &p1, int &p2)  
{ 
    cout<<"引用>>"<<endl;
    int p = p1;
    p1 = p2;
    p2 = p;
}

//指针作为函数的形参
void swap(int *p1, int *p2)
{
    cout<<"指针>>"<<endl;
    int p = *p1;
    *p1 = *p2;
    *p2 = p;
}

int main()
{ 
    int a = 1, b = 2;
    swap(a, b);  //直接以变量a和b作为实参调用swap函数 
    cout<<a<<' '<<b<<endl;  //输出结果 
}

输出：
引用>>
2 1

// -------------
...
swap(&a, &b);
...
输出
指针>>
2 1
```

```c++
// 值传递
..
void swap(int p1, int p2)
{
    cout<<"值传递>>"<<endl;
    int p = p1;
    p1 = p2;
    p2 = p;
}
...
输出
值传递>>
1 2
```

**`注意：`**
`swap(int p1, int p2)` 和 `swap(int &p1, int &p2)` 同时存在会报错：`call to 'swap' is ambiguous`。说明编译器无法区分值传递和引用传递。

**`总结：`**

1. 引用作为函数形参和指针作为函数形参的效果是一样的，在函数中修改形参的值会影响到实参。
2. 使用引用作为函数参数不会产生实参的副本，它是直接对实参进行操作，所以当参数传递的数据较大时，用引用较好。
3. 使用指针虽然也能到达和使用引用的效果，但是在函数内同样要给形参分配存储单元，且需要重复使用 `*指针变量名` 的形式进行运算。

### 作为函数返回值

当函数返回值为指针或引用时，调用函数返回的是什么？

为什么会有这个问题呢，在项目中可能会看到返回值为引用的函数出现在了 `=` 的左边，那可能会有疑问，返回值为指针的函数可不可以？

答案是不可以，为什么？

* **返回值为引用**：变量别名；既然是变量那当然可以给它赋值；
* **返回值为指针**：指针的值（指的是那一串代表内存地址的值）；就像 `10` 无法出现在 `=` 左侧一样。

> 可以赋值给普通变量吗，可以。但是会发生 **拷贝**！

示例：

```c++
#include <iostream>

int* getPointer() {
    static int val = 42;
    return &val;
}

int& getReference() {
    static int val = 100;
    return val;
}

int main() {
    // 通过指针赋值
    *getPointer() = 50;   // OK
    std::cout << *getPointer() << std::endl; // 输出 50

    // 通过引用赋值
    getReference() = 200; // OK
    std::cout << getReference() << std::endl; // 输出 200

    // getPointer() = &some_other_variable; // ❌ 不允许
}
```

下面有几个比较典型使用的例子：

1. **使用 `C++` 代码实现 `Java` 中类静态变量的能力**：

```java
public class Test {
    public static int num = 0;

    public int getNum () {
        return num;
    }

    public static void main(String[] args) {
        Test test = new Test();
        Test.num = 10;
        System.out.println(test.getNum());
    }
}
```

```c++
class Test {
public:
    // 返回引用，允许链式调用和赋值操作
    static int& getValue() {
        static int value = 0;
        return value;
    }
};

int main() {
    Test::getValue() = 10; // 链式调用
    cout << Test::getValue() << endl; // 输出结果为10
    return 0;
}
```
