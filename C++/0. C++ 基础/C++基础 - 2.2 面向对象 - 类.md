##### 1.1.1.2 初始化列表

**`作用`**：

初始化列表作用是对变量赋值，和在构造函数中对变量进行赋值效果一样。

**`使用场景`**：

* `const` 成员变量。

**`示例：`**

```c++
#include <iostream>
using namespace std;
 
class Test {
private:
    const int a;
    int b;

public:
    Test(int v1, int v2);
    int getValueA(){
        return a;
    }
    int getValueB(){
        return b;
    }
};

Test::Test(int v1, int v2):a(v1){
    b = v2;
}

// 等价于
Test::Test(int v1, int v2):a(v1), b(v2){
}

int main ()
{
   Test test1 = Test(4, 6);
   cout<<test1.getValueA()<<endl;
   cout<<test1.getValueB()<<endl;
 
   return 0;
   }
```

### 1.1.2 拷贝构造函数
**`作用：`**

拷贝构造函数用于使用已有的对象生成一个**新的对象**。

**`语法：`**
```c++
// 以相同类对象的引用为入参
classname (const classname &obj)
```

**`调用场景：`**

* 通过使用另一个同类型的对象来初始化新创建的类对象（`=` 赋值）。
* 作为参数传递给函数。
* 作为函数返回值。

> 注意：作为参数传递给函数或作为函数返回值时可能由于编译器优化而不会触发拷贝。

**`深拷贝：`**

`c++` 类提供默认拷贝构造函数，仅当类成员中含有指针类型成员且需要对其分配内存时我们需要重写拷贝构造函数完成深拷贝。深拷贝的作用在于创建新的内存空间并将原对象内存空间的值拷贝存入新的内存空间，已防止重复释放。

> 这里可能会有一个疑问，如果一个类 `A` 中包含一个类对象 `B` 那触发拷贝时为什么不用重新分配空间？这是因为如果这个对象是在类的构造过程中被创建的那么它的创建就和拷贝无关了，正常新建一个新的 `A` 类对象，也会创建类对象 `B`。而如果是由外部传入，那么它肯定也触发了拷贝，传入的其实是一个新的类对象了。

**`浅拷贝示例：`**

```c++
#include <iostream>
using namespace std;

class Test
{
public:
    Test(int *len);
    ~Test();
    int *length;
};

Test::Test(int *len)
{
    length = len;
    cout<<"构造"<<endl;
}
Test::~Test()
{
    cout<<"析构"<<endl;
    delete length;
}

int main(int argc, char const *argv[])
{
    Test obj1(new int(10));
    cout<<obj1.length<<endl;
    Test obj2 = obj1;
    cout<<obj2.length<<endl;
    return 0;
}
```
输出：
```c++
构造
0x7f8926c026d0
0x7f8926c026d0
析构
析构
main2(31584,0x7fffa101d380) malloc: *** error for object 0x7f8926c026d0: pointer being freed was not allocated
```

#### 1.1.3.1 左值和右值

在 `C++` 或者 `C` 语言中，一个表达式（可以是字面量、变量、对象、函数的返回值等）根据其使用场景不同，分为左值表达式和右值表达式。

**左值（lvalue）**：指存储在内存中、有明确存储地址（可寻址）的数据；
**右值（rvalue）**：指的是那些可以提供数据值的数据（不一定可以寻址，例如存储于寄存器中的数据：整数值、字符串值这些）；

**`判断左值右值的两种方式：`**

* 可位于赋值号（=）左侧的表达式就是左值；反之，只能位于赋值号右侧的表达式就是右值。

```c++
int a = 5;
5 = a; //错误，5 不能为左值

int b = 10; // b 是一个左值
a = b; // a、b 都是左值，只不过将 b 可以当做右值使用
```

* 有名称的、可以获取到存储地址的表达式即为左值；反之则是右值。

以上面定义的变量 `a、b` 为例，`a` 和 `b` 是变量名，且通过 `&a` 和 `&b` 可以获得他们的存储地址，因此 `a` 和 `b` 都是左值；反之，字面量 `5、10`，它们既没有名称，也无法获取其存储地址（字面量通常存储在寄存器中，或者和代码存储在一起），因此 `5、10` 都是右值。 

> 注：以上两种方式仅适用大部分场景。

#### 1.1.3.2 右值引用

我们知道 `&` 表示引用，在 `C++98/03` 标准中通常只有左值引用，没有右值引用。示例：


常量引用除外。示例：


**`右值引用特点：`**

* 所引用的对象将要被销毁；
* 该对象没有其他用户；

因此右值引用的代码可以自由地接管所引用的对象的资源。

> 注意：无论是左值引用还是右值引用都必须在定义时赋值。

#### 1.1.3.3 移动构造函数

**`语法：`**
```c++
classname (classname &&obj)
```

**`作用：`**
移动构造函数首先将传递参数的内存地址空间接管。然后将内部所有指针设置为 `nullptr`，并且在原地址上进行新对象的构造，最后调用原对象的析构函数，这样做既不会产生额外的拷贝开销，也不会给新对象分配内存空间。

**`调用时机：`**
默认情况下，使用同类的右值对象初始化新对象时，调用移动构造函数；使用同类的左值对象初始化新对象时，调用拷贝构造函数。

**`示例：`**

```c++
#include <iostream>
using namespace std;

class Test
{
public:
    Test(int *len)
    {
        cout<<"构造"<<endl;
        length = len;
    }
    Test(const Test &obj)
    {
        cout<<"深拷贝"<<endl;
        length = new int(*obj.length);
    }
    Test(Test &&obj)
    {
        cout<<"移动 ~~~~~"<<endl;
        cout<<this<<endl;
        cout<<&obj<<endl;
        length = obj.length;
        obj.length = NULL;
        cout<<"移动 ~~~~~"<<endl;
    }
    ~Test()
    {
        cout<<"析构 << "<<this<<endl;
        delete length;
    }
    int *length;
};

Test getNewObj(Test obj)
{
    cout<<"getNewObj << "<<&obj<<endl;
    return obj;
}

int main(int argc, char const *argv[])
{
    Test obj1(new int(10));
    cout<<"main.obj1 << "<<&obj1<<endl;
    Test obj2 = getNewObj(obj1);
    cout<<"main.obj1 << "<<&obj1<<endl;
    cout<<"main.obj2 << "<<&obj2<<endl;
    return 0;
    }
```
输出：
```c++
构造
main.obj1 << 0x16ee132f8
深拷贝
getNewObj << 0x16ee132d8
移动 ~~~~~
0x16ee132e0
0x16ee132d8
移动 ~~~~~
析构 << 0x16ee132d8
main.obj1 << 0x16ee132f8
main.obj2 << 0x16ee132e0
析构 << 0x16ee132e0
析构 << 0x16ee132f8
```

> **移动构造调用时机**：应该是在 `getNewObj` 函数返回赋值给 `obj2` 时。编译器判断 `getNewObj` 函数的入参即将被销毁所以调用了移动构造函数节省内存空间而不是拷贝构造函数。

### 1.2.1 内联函数
[C语言中内联函数的作用 inline](https://bbs.huaweicloud.com/blogs/275446)

**`定义`**：
使用 `inline` 修饰的函数为内联函数，在类定义体内定义的函数默认为内联函数。

**`作用`**：
在`编译期`，`建议`编译器将内联函数的实现在当前位置展开。因为函数调用涉及得入栈出栈，影响效率，使用内联函数将省去这部分开销。

**`优缺点`**：

* 优点：内联函数没有执行函数调用的开销，加快了程序运行时间；
* 缺点：内联函数是将整个函数体的代码插入到调用语句处，会增大代码的大小，增大内存的占用。

**`使用场景`**：
代码体量不是很大（无for、while、递归等）又频繁被调用的函数建议声明为内联函数。

#### 1.2.1.1 内联函数 & 虚函数

[C/C++ 技术面试基础知识总结](https://github.com/huihut/interview)

* 虚函数可以是内联函数，内联是可以修饰虚函数的，但是当虚函数表现多态性的时候不能内联。
* 内联是在编译期建议编译器内联，而虚函数的多态性在运行期，编译器无法知道运行期调用哪个代码，因此虚函数表现为多态性时（运行期）不可以内联。
* `inline virtual` 唯一可以内联的时候是：编译器知道所调用的对象是哪个类（如 `Base::who()`），这只有在编译器具有实际对象而不是对象的指针或引用时才会发生。

```c++
#include <iostream>  
using namespace std;
class Base
{
public:
	inline virtual void who()
	{
		cout << "I am Base\n";
	}
	virtual ~Base() {}
};
class Derived : public Base
{
public:
	inline void who()  // 不写inline时隐式内联
	{
		cout << "I am Derived\n";
	}
};

int main()
{
	// 此处的虚函数 who()，是通过类（Base）的具体对象（b）来调用的，编译期间就能确定了，所以它可以是内联的，但最终是否内联取决于编译器。 
	Base b;
	b.who();

	// 此处的虚函数是通过指针调用的，呈现多态性，需要在运行时期间才能确定，所以不能为内联。  
	Base *ptr = new Derived();
	ptr->who();

	// 因为Base有虚析构函数（virtual ~Base() {}），所以 delete 时，会先调用派生类（Derived）析构函数，再调用基类（Base）析构函数，防止内存泄漏。
	delete ptr;
	ptr = nullptr;

	return 0;
} 
```

### 1.2.2 赋值运算符
通过赋值运算符为类对象赋值时，如果类中存在指针变量那么要特别注意不要重复释放指针。可以重载赋值运算符将被赋值类对象的指针释放并新建指针。或者在析构函数中在释放指针前做判空处理（但是这种方式无效需要分析原因）。

```c++
#include <iostream>
using namespace std;

class Test
{
public:
    Test(int *len);
    Test(const Test& other);
    ~Test();
    Test& operator=(const Test& other);
    int *length;
};

Test::Test(int *len)
{
    length = new int(*len);
    cout<<"构造"<<endl;
}

Test::Test(const Test& other)
{
    length = new int(*other.length);
    cout<<"拷贝构造"<<endl;
}

Test::~Test()
{   
    if (length)
    {
        cout<<"析构"<<length<<endl;
        delete length;
        length = nullptr;
    }
}

Test& Test::operator=(const Test& other)
{
    if (this == &other)
    {
        return *this;
    }

    if (length)
    {
        delete length;
        length = nullptr;
    }

    length = new int(*other.length);
    cout<<"赋值运算符"<<endl;

    return *this;
}

int main(int argc, char const *argv[])
{
    Test obj1(new int(10));
    Test obj2(new int(11));
    obj2 = obj1;
    return 0;
}
```

### 1.2.3 重载
#### 1.2.3.1 函数重载

**`定义：`**
函数名相同，但是形式参数（指参数的个数、类型或者顺序）不同的函数。
> 仅返回值类型不同的函数不是重载函数。

#### 1.2.3.2 运算符重载
以赋值运算符重载举例。

**`示例：`**
```c++
#include <iostream>
using namespace std;

class Distance
{
   private:
      int feet; 
      int inches;
   public:
      // 构造函数
      Distance(){
         feet = 0;
         inches = 0;
      }
      // 赋值运算符重载
      Distance& operator=(const Distance &D )
      {
         cout<<"赋值运算"<<endl;
         feet = D.feet;
         inches = D.inches;
         return *this;
      }
};

int main(int argc, char const *argv[])
{
    Distance one;
    Distance two;
    Distance three;
    one = two = three;
    return 0;
}
```

重载运算符返回值的类型声明为类的引用，才可以连续赋值，例如：a = b = c;

> **`注意`**：`operator=` 代表的赋值运算符，等号两边不添加空格。

**`调用场景：`**
使用一个对象的值赋值给另外一个已存在对象。

# 2. 初始化类对象

## 2.1 初始化类对象

[对象初始化的方式](https://www.jianshu.com/p/42b3ee097b2f)

创建类对象有如下三种方式：

* **`隐式初始化`**：在栈上分配内存，仅适用于存在默认构造函数或构造函数无需传参的场景。

```c++
A a;    // 等价于 A a = A();
```

* **`显示初始化`**：在栈上分配内存。

```c++
A a = A();
// c++ 11 后可以使用{}替代()初始化对象
A a = A{};
```

* **`new 对象指针`**：在堆中动态分配内存。

```c++
A *a = new A();    // 记得要 delete a;
```
> **`注意`**：
> - `A a;` 隐式使用默认构造函数时，变量a后面不能加括号，否则 `A a();` 会被编译器认为是函数声明。
> - 注意区分初始化和赋值，使用已有类对象初始化新对象会调用拷贝构造函数，而赋值已有类对象则会调用赋值运算符。

## 2.2 对象销毁
通常情况下，不需要手动使用 `delete` 来释放在栈上分配的类对象。只有在你使用 `new` 手动分配内存时，需要使用 `delete` 来释放这些对象，以避免内存泄漏。

释放对象：
```c++
A *a = new A();
...
delete a;
```

释放对象数组：
```c++
A *a = new A[10];
...
delete[] a;
```

## 2.3 对象 vs 对象指针

通过隐式、显示调用构造函数创建的类对象和使用关键字 `new` 创建的对象指针区别总结如下：

* **创建方式不同**：对象指针通过关键字 `new` 创建。
* **销毁方式不同**：生命周期结束后，`new` 创建的对象指针需要使用 `delete` 回收，不然会造成`内存泄漏`；其他方式创建的对象会被操作系统自动调用其析构函数回收。
* **内存位置不同**：`new` 在堆空间分配内存，其他方式在栈空间分配内存。
* **使用方式不同**：对象通过 `.` 访问类成员，对象指针通过 `->` 访问类成员。
* **使用场景不同**：根据内存位置的不同可知，频繁创建销毁的不适合使用 `new` 创建对象，例如：频繁调用的函数、作为函数入参或返回值。

# 3. struct
**`struct 和 class 的区别：`**

* **默认继承访问权：**`class` 默认继承权限是 `private`, `struct` 默认继承权限是 `public`。
* **默认访问权限：**`class` 默认访问权限是 `private`, `struct` 默认访问权限是 `public`。

> `注意`：`struct` 不可用于定义模板是错误的。

**`使用场景`**：

* **`struct`**：通常用于简单的数据结构，尤其是当所有成员都需要公开访问时。
* **`class`**：通常用于更复杂的对象，尤其是当需要封装和数据隐藏时。
