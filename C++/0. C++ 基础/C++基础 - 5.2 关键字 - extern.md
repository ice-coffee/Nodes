#### 全局变量

**`定义`**：在所有函数外部定义的变量（通常是在程序的头部），称为全局变量。

**`作用`**：全局变量可以被任何函数访问。也就是说，全局变量一旦声明，在整个程序中都是可用的。全局变量的值在程序的整个生命周期内都是有效的。

**`覆盖`**：局部变量和全局变量的名称可以相同，但是在函数内，局部变量的值会覆盖全局变量的值。

#### 变量定义 & 声明
**`定义`**：
* **变量声明**：不分配存储空间，用于向程序表明变量的类型和名字。
* **变量定义**：用于为变量分配存储空间，还可为变量指定初始值，程序中，变量有且仅有一个定义。

根据C++标准的规定，一个变量声明必须同时满足两个条件，否则就是 **「定义」**：

1. **声明必须使用 `extern` 关键字**；
2. **不能给变量赋初值**。

```c++
//声明一个外部变量：（通过使用extern关键字，可以声明变量名而不定义它）
extern int Number；
//定义一个变量
int Number;
```

如果声明有初始化式，就被当作定义，即使前面加了 `extern`。

```c++
//是extern声明，也是定义，因为对变量进行了初始化
extern double pi=3.1416; 
```

#### 函数定义 & 声明
**`定义`**：
* **函数声明**：（又称函数原型）函数原型之于函数，相当于变量声明之于变量，只有函数头的就是函数原型。
* **函数定义**：带有函数体的就是定义。

**`注意`**：
* 函数原型的返回值类型与函数定义必须相同。
* 函数原型的形参表的类型与顺序必须与函数定义相同，但是函数原型可以不写形参名称，即便写了形参名称也可以和原函数不一样。

### extern 关键字
`extern` 关键字有两个作用：
1. 当它与 "`C`" 一起连用时，如: `extern "C" void fun(int a, int b);`则告诉编译器在编译fun这个函数名时按着C的规则去翻译相应的函数名而不是C++的。
2. 当 `extern` 关键字修饰变量或函数时用于声明变量或函数，告诉编译器变量或函数在其他地方定义了。
3. 只有当 `extern` 变量声明位于函数外部时，才可以被初始化。

#### 访问全局变量
**`注意`**：
* 变量定义不要放在 `.h` 文件中，这会导致重复定义的错误；
* 可以在头文件中声明一个变量，在用的时候包含这个头文件就声明了这个变量；

**`示例`**：

**`test1.h`**

```c++
void modify_1();
```

**`test1.cpp`**

```c++
#include <iostream>
#include "test1.h"

using namespace std;

int global_v = 1;

void modify_1()
{
    global_v++;
    cout<<"test1, global_v = "<<global_v<<endl;
}
```

**`test2.h`**

```c++
extern int global_v;

void modify_2();
```

**`test2.cpp`**

```c++
#include <iostream>
#include "test2.h"

using namespace std;

void modify_2()
{
    global_v++;
    cout<<"test2, global_v = "<<global_v<<endl;
}
```

**`main.cpp`**

```c++
#include <iostream>
#include "test1.cpp"
#include "test2.cpp"

using namespace std;

int main(int argc, char const *argv[])
{
    modify_1();
    modify_2();
    return 0;
}
```

**`总结`**：
1. 变量在使用之前要被定义或者声明；
2. 变量只能被定义一次，但是可以被声明很多次；
3. 定义会分配相应的存储空间，但是声明不会；

#### 访问全局函数
告诉编译器此函数在其他地方定义了；
```c++
extern int test();
```

### 扩展
以下三种实体的定义也可以放到头文件中：

1. 值在编译时就已知的 `const` 变量的定义可以放到头文件中；
2. 类的定义；
3. `inline` 函数；

这三个实体可以定义在多个源文件中，只要在每个源文件中的定义相同。
