### 工具链结构
```
gcc-arm-9.2-2019.12-x86_64-aarch64-none-linux-gnu
```

* **`gcc-arm`**：基于 `GCC` 的 `ARM` 架构工具链。专门用于编译 `ARM` 架构代码。
* **`9.2`**：`GCC` 的主版本号为 `9.2`。
* **`2019.12`**：工具链的发布时间。
* **`x86_64`**：工具链本身需要运行在 `64` 位 `x86` 系统上。
* **`aarch64`**：工具链的目标平台是 `AArch64（ARM64 位）` 架构。
* **`none`**：工具链的 供应商字段为空，表示这是通用工具链，未针对特定厂商定制。对比：`arm`：官方 `ARM` 公司发布的工具链；`linaro`：`Linaro` 社区优化的工具链。
* **`linux-gnu`**：目标系统的操作系统和 `ABI`（应用二进制接口）。`linux`：目标程序运行在 `Linux` 系统上；`gnu`：使用 `GNU C` 库（`glibc`）和 `GNU ABI`。
