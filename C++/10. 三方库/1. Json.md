### 常用 JSON 库

| 库名 | 特点 |
| --- | --- |
| **[nlohmann/json](https://github.com/nlohmann/json)**     | 语法简洁，类似 Python 风格，使用广泛，支持自动序列化 |
| [RapidJSON](https://github.com/Tencent/rapidjson)         | 高性能、轻量级，适合性能要求高的项目     |
| [JsonCpp](https://github.com/open-source-parsers/jsoncpp) | 老牌库，语法稍显复杂             |

### nlohmann/json

#### 使用

**`使用方式 1：单头文件`**

只需要下载一个头文件：

```bash
wget https://github.com/nlohmann/json/releases/download/v3.11.3/json.hpp
```

**`使用方式 2：CMake`**

```cmake
find_package(nlohmann_json REQUIRED)
target_link_libraries(your_target PRIVATE nlohmann_json::nlohmann_json)
```

#### 示例

假设我们有一个 JSON 字符串如下：

```json
{
  "name": "Tom",
  "age": 25,
  "is_student": false,
  "skills": ["C++", "Python", "Java"]
}
```

**`解析：`**

```cpp
#include <iostream>
#include <nlohmann/json.hpp>

int main() {
    std::string json_str = R"({
        "name": "Tom",
        "age": 25,
        "is_student": false,
        "skills": ["C++", "Python", "Java"]
    })";

    nlohmann::json j = nlohmann::json::parse(json_str);

    std::string name = j["name"];
    int age = j["age"];
    bool is_student = j["is_student"];
    std::vector<std::string> skills = j["skills"];

    std::cout << "Name: " << name << "\n";
    std::cout << "Age: " << age << "\n";
    std::cout << "Is student: " << is_student << "\n";
    std::cout << "Skills:\n";
    for (const auto& skill : skills) {
        std::cout << " - " << skill << "\n";
    }

    return 0;
}
```

---

**`构造 JSON：`**

```cpp
#include <iostream>
#include <nlohmann/json.hpp>

int main() {
    nlohmann::json j;
    j["name"] = "Alice";
    j["age"] = 30;
    j["is_student"] = true;
    j["skills"] = {"Go", "Rust"};

    std::cout << j.dump(4) << std::endl; // 美化输出（4空格缩进）
}
```

---

**`错误处理：`**

```cpp
try {
    auto j = nlohmann::json::parse("invalid json");
} catch (nlohmann::json::parse_error& e) {
    std::cerr << "Parse error: " << e.what() << std::endl;
}
```
