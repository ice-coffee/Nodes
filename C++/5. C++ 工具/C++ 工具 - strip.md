**`介绍`**：

`strip` 命令用于移除可执行文件、目标文件或库文件中的符号表和调试信息，从而减小文件体积。通常在发布软件时使用，以减少存储占用并提升加载速度。

**`语法`**：

```bash
strip [选项] 文件...
```

**`常用选项`**：

* -s 或 --strip-all：移除所有符号表和重定位信息（默认）。
* -g 或 --strip-debug：仅移除调试信息，保留符号表。
* -o <文件>：指定输出文件。
* -R <段名> 或 --remove-section=<段名>：移除指定段。
* --help：显示帮助信息。
* --version：显示版本信息。

**`示例`**：

```bash
// 移除所有符号表和调试信息
strip demo.so
// 仅移除调试信息
strip -g demo.so
// 指定输出文件
strip -o demo_new.so demo.so
```
