`nm` 是属于 **GNU Binutils 工具集**的一部分，用来查看目标文件（`.o`、`.a`、`.so`、可执行文件等）里的**符号表信息**。

### 简介

**命令全名：** “name list”
**主要作用：**

列出二进制文件（目标文件、静态库、动态库、可执行文件）中的所有符号（函数、变量、符号地址等）。

你可以理解为：

> `nm` = “看二进制文件里有哪些函数和变量”。

### 语法

```bash
nm [选项] <文件>
```

常见选项：

| 选项 | 说明 |
| ---- | ---- |
| `-C`| 将 C++ 符号名还原成可读的函数名 |
| `-D`| 仅显示动态符号（动态库导出符号） |
| `-u`| 仅显示未定义符号 |
| `-g`| 仅显示外部（global）符号  |
| `--defined-only` | 仅显示已定义的符号 |
| `-S`| 显示符号大小 |
| `-n` 或 `--numeric-sort` | 按地址排序 |
| `-l` | 显示符号对应的源代码行号 |

### 输出格式

```
[地址] [类型] [符号名]
```

示例输出：

```bash
0000000000001130 T _main
0000000000001100 t helper_func
0000000000000000 B global_var
                 U printf
```

常见符号类型：

| 符号 | 含义 |
| ----- | -------------------------- |
| **T** | 定义在代码段中的函数 |
| **B** | 定义在未初始化数据段（.bss）中的变量 |
| **D** | 定义在已初始化数据段（.data）中的变量 |
| **R** | 定义在只读数据段（.rodata）中的变量 |
| **W** | 弱符号（weak symbol） |
| **A** | 绝对符号（不会被重定位） |
| **C** | 未初始化的 common 符号（旧式变量声明） |
| **U** | 未定义符号（依赖外部库）|

`T,t`、`B,b`、`D,d`、`R,r`：
对于编译器、链接器和 nm 输出而言：

* 大写：global，链接库可访问；
* 小写：local，链接库不可访问；

| 符号类型 | 所在段 | 含义 | 可见性 | 常见来源  |
| --- | --- | --- | --- | --- |
| **T / t** | `.text` | 全局函数/静态函数 | T → 全局符号，可导出；t → 文件内静态符号，只能在本文件使用 |  |
| **B / b** | `.bss` 段 | 未初始化的全局或静态变量 | B → 全局变量，其他目标可访问；b → 文件内静态变量 | `int x; static int y;` |
| **D / d** | `.data` 段| 已初始化的全局或静态变量 | D → 全局变量；d → 文件内静态变量 | `int x = 1; static int y = 2;` |
| **R / r** | `.rodata` 段 | 只读数据（常量区） | R → 全局常量，可被其他目标引用；r → 文件内静态常量 | `const int x = 1; 字符串常量`  |

### 使用示例

| 功能          | 命令                |            |
| ----------- | ----------------- | ---------- |
| 查看符号列表      | `nm file.o`       |            |
| 只看未定义符号     | `nm -u file.o`    |            |
| 还原 C++ 符号名  | `nm -C file.o`    |            |
| 看动态库导出符号    | `nm -D libxxx.so` |            |
| 检查 JNI 方法导出 | nm -D libxxx.so   | grep Java_ |
